# Изменения

## 2.9.3-beta.1 — первый предварительный выпуск через GitHub

- PulseDeck привязан к официальному репозиторию `viktorstriuk/PulseDeck` и проверяет
  подписанные манифесты обновлений с закреплённым публичным Ed25519-ключом.
- Компоненты yt-dlp и FFmpeg/FFprobe остаются независимыми от канала приложения и
  продолжают обновляться по проверяемым каталогам издателей.
- GitHub Actions собирает Windows x64, прогоняет Node/Go/Chromium-проверки, создаёт
  исходный архив и подписывает beta-feed перед созданием черновика Release.
- Стабилизированы browser CI-проверки системной темы, перетаскивания источников и
  resize-зоны игрового оверлея; в тестовую среду явно добавлен Pillow.
- Этот prerelease предназначен для проверки настоящей цепочки обновления на Windows;
  он не публикуется в stable-feed.

## 2.9.2 — редактирование треков, обложки и подтверждённый импорт

- Подменю трека с правкой исполнителя/названия без изменения аудиоданных,
  проверкой ревизии и сохранением идентификаторов/избранного/привязки текстов.
- Поиск обложек: включённые музыкальные источники, затем MusicBrainz / CAA;
  сетка 4×N, локальная картинка, выбор по клику и SVG автора.
- Ссылки в основной поисковой строке, закреплённый исходный трек и альтернативы.
- Динамические действия плейлиста: неизвестные исполнители, отсутствующие обложки,
  синхронизированные тексты; подтверждение, прогресс, отмена оставшейся очереди.
- Безопасная предварительная проверка папок, аудио, ZIP и TAR/TGZ перед копированием;
  защита путей, CRC/размеров ZIP и контроль целостности gzip. RAR/7z/ZIP64 не входят.
- Нет полной повторной индексации библиотеки на каждую правку в пакетном задании:
  один снимок списка, актуальные теги/ревизия каждого файла при записи.
- Обложки закрытых треков шифруются; замена обложки не отзывает токен текущего аудио.
- Ошибки сервиса не выдаются за отсутствие совпадений, старый ответ не подменяет
  новый запрос. Ручные тексты и уже заполненные поля не заменяются автоматикой.

## 2.9.1 — полировка поиска и локальные компоненты

- Исправлен ввод пробелов: отображаемое значение не нормализуется после каждого символа
- Иконки источников, плавные переключения, прокрутка/перетаскивание без видимого скроллбара
- Отдельная панель фильтров и свёрнутые ошибки источников за кнопкой «…»
- Иконки команд, меньше подсказок, общий поиск из пустой локальной выдачи
- Общая громкость основного плеера и предпрослушивания, отдельная кнопка mute у таймера
- Исправлены прокрутка всего окна настроек скрытым checkbox и вертикальное выравнивание
- Независимая проверка обновлений компонентов у издателей без репозитория PulseDeck
- Только локальные инструменты в папке установки, проверка обоих файлов FFmpeg/FFprobe
- Установка компонентов до завершения Setup, SHA-256, ограниченная распаковка и probe
- Миграция только пути компонентов с резервной копией, без переноса музыки и профиля

## 2.9.0 — общий музыкальный поиск

- Шесть источников, поиск при вводе, включение источников и изменение приоритета
- Единое плавающее/развёрнутое окно, фильтры, подгрузка и устранение дубликатов
- Проверки доступности без приравнивания сетевых ошибок к DRM
- Локальные рекомендации по добровольно включаемой истории
- Метаданные поиска без обязательной установки yt-dlp


## 2.8.2 - раздельные стили и режим чтения

- Семь независимых групп оформления, общий шаблон и возврат выбранной группы к нему
- Системная палитра независимо от темы/акцента приложения
- Текст песни без нижней панели инструментов, автоскрытие интерфейса через 3,5 секунды
- Двухслойные переходы фона с ограниченной очередью и поддержкой уменьшенного движения
- Поиск/экспорт в редакторе, сохранение черновика при запросе пароля защищённого экспорта
- Увеличенная и поднятая аватарка; исправление заливки и выравнивания «Новый плейлист»
- Контуры фокуса только при работе с клавиатурой; три новых пастельных градиента иконки
- RU/EN, тесты независимых профилей, таймера, переходов и регрессий

## 2.8.1 - формулировки и установщик

- Редактура RU/EN: короткие действия, меньше повторов, без конечных точек и длинных тире в штатном интерфейсе
- Компактный статичный блок MusheP, точная авторская подпись и безопасное форматирование строки исполнения
- Выбор языка установщика через список с флагами, управление мышью и клавиатурой
- Начальный язык по системному UI, сохранение выбора для приложения после успешной установки
- Системная светлая/тёмная тема основного установщика и стартового графического окна
- Предоставленный user-off.svg, новая левая надпись и адаптивные размеры
- Миграция известных старых штатных значений языков с точной резервной копией, без потери пользовательских правок
- Проверки переключения языка, шаблонов, миграции, безопасной записи настроек и геометрии в Playwright

## 2.8.0 — публичная основа и обслуживание приложения

- MIT / MusheP, раздел «О PulseDeck», авторская PNG, пять социальных ссылок,
  раскрываемые credits и предоставленный `link.svg`.
- Центр обновлений: отключаемая фоновая проверка, opt-in beta, проверка
  Ed25519/SHA-256, загрузка/отмена, перезапуск/следующий запуск, защита редактора.
- Настраиваемый официальный GitHub источник; в этой сборке repo/public key
  отсутствуют намеренно, источник не угадывается из социального профиля.
- Управляемые версии FFmpeg/FFprobe и yt-dlp: одобряемый подписанный каталог,
  pins первого использования, staging/probe/hash, занятость и явный откат.
- Графический установщик/удаление с собственными controls и выбором папки,
  прозрачной областью под выступающий знак. Go web-bootstrap без консоли,
  pinned runtime, journal/rollback и ограниченный список принадлежащих файлов.
- Карта постоянных путей, безопасный переход старой библиотеки без её переноса,
  profile/languages overrides поверх штатных каталогов.
- Инструменты подписи/упаковки исходников, документация, MIT/сторонние лицензии,
  CI и workflow для черновика выпуска. Windows-приёмка остаётся отдельным этапом.
