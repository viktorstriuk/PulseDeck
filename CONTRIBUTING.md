# Участие в PulseDeck

Собственный код — MIT. Пожалуйста, сохраняйте авторство MusheP и уведомления
сторонних проектов. Для графики указывайте **точную страницу ресурса**, лицензию,
автора, изменения и SHA-256 в `docs/assets-provenance.json` / CREDITS. Ссылка на
главную страницу сайта не заменяет сведения о лицензии отдельной иконки.

Присылайте небольшие изменения с воспроизводимым тестом. Не включайте личную
музыку, пароли, production-ключи, cookies, EXE из интернета и результаты браузерных
прогонов. Исходники программы размещаются обычными файлами; готовые сборки —
в Releases. Перед первым push проверьте также скрытые файлы и Git history.

Новый видимый текст помещается в ru.json/en.json с одинаковыми ключами. Не
переводите пользовательские названия треков, заметки или текст песни. Сохраняйте
порядок fallback выбранный язык → en → ключ, проверяйте обе локали, клавиатуру,
уменьшенное движение и узкое окно. Новые IPC должны проверять sender/mainFrame,
валидировать значения и не принимать произвольные исполняемые пути от renderer.

Команды сборки и тестов — в docs/building.md. Результаты в `test-results` являются
локальными/CI-артефактами. В pull request указывайте, что действительно проверено:
Chromium с тестовым IPC, Go на Linux, кросс-компиляция, установленный Electron на
Windows — разные проверки. Изменения обновлятора/установщика требуют тестов
сбойных сценариев и явной Windows-приёмки.

Версии компонентов не одобряются автоматически только потому, что upstream
опубликовал более свежий номер. Проверьте бинарную лицензию, соответствующие
исходники, хеш, архитектуру и совместимость. Подписанные production-feed выпускает
только владелец доверенного ключа.
