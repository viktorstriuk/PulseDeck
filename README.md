# PulseDeck 2.9.2

Локальный музыкальный плеер для Windows x64. Автор — **MusheP**.
Собственный код распространяется под [MIT](LICENSE). Музыка остаётся на
компьютере: библиотека, плейлисты, тексты песен, настройка оформления и отдельный
мини-плеер. Проект не связан с владельцами внешних сервисов.

## Что нового

В 2.9.2 у трека появилось подменю «Поменять в треке»: редактирование исполнителя
и названия, собственная обложка и поиск обложек в соседней плавающей панели.
Сначала используются включённые музыкальные источники, затем MusicBrainz /
Cover Art Archive. В выдаче только изображения; выбор сохраняется одним кликом.
Правки метаданных записываются в `.pulse.json`, а не в аудиофайл.

В основную поисковую строку можно вставить ссылку на поддерживаемый одиночный
трек: разрешённый результат закрепляется первым, затем подбираются альтернативы.
Отдельное поле ссылки удалено. Для разрешения ссылки нужен локальный yt-dlp.

Контекстное меню плейлиста предлагает только нужные пакетные действия:
восстановление неизвестного исполнителя из «Исполнитель - Название», поиск
недостающих обложек и подходящих синхронизированных текстов. Существующие данные
не затираются. Одна команда показывается сразу; несколько — в «Дополнительно».

Треки, папки и ZIP / TAR / TAR.GZ / TGZ можно перетащить в окно. До копирования
показываются число треков, папка назначения и необязательные улучшения.
RAR, 7z, ZIP64, зашифрованные и вложенные архивы не поддерживаются. Исходные файлы
не удаляются. Остановка прерывает оставшуюся очередь, сохраняя уже скопированное.

[Редактирование и импорт](docs/library-tools-2.9.2.md) ·
[Проверки и ограничения](docs/verification-2.9.2.md)

Все изменения поиска и независимых обновлений компонентов 2.9.0–2.9.1 сохранены.
[Архитектура поиска](docs/research/search-2.9.0.md) · [Компоненты](docs/updating.md).

**Живые сервисы, Windows File Drop и интерактивная установка в сборочной среде
не проверены.** Сетевые ответы и IPC в тестах контролируемые; реальные HTML/JS/CSS
проверяются в Chromium. Это не гарантия доступности внешних сайтов в конкретной сети.

Центр обновлений поддерживает фоновую проверку, отдельный beta-канал, загрузку
с перезапуском или установку при следующем запуске, отмену загрузки и проверку
подписи Ed25519 + SHA-256. FFmpeg/FFprobe обновляются парой; yt-dlp — отдельно,
по HTTPS-каталогам издателей с SHA-256. При настройке подписанного собственного
канала сохраняется поддержка одобренного каталога. Версии сохраняются для возврата.

**Официальный репозиторий ещё не назначен.** В `app/updates/config.json` намеренно
оставлены `repository: null` и пустой публичный ключ. Проверка обновлений самого PulseDeck не
обращается в сеть и не выдаёт это за «последнюю версию». Профиль автора GitHub
не используется как репозиторий приложения. См. [подключение источника](docs/updating.md).

Установщик полностью графический: собственное окно, кнопки, выбор папки,
прогресс и экран завершения; знак PulseDeck выступает над нарисованной панелью.
Он использует прозрачную область своего окна, а не рисует вне границ OS-окна.
Начальная загрузка среды также имеет собственное графическое окно без консоли.

## Установка и переход с предыдущей версии

Закройте PulseDeck. Сохраните резервные копии `music`, `data` со скрытыми файлами
и `%APPDATA%\PulseDeck`. Запустите `PulseDeck-Setup-2.9.2.exe` и при обновлении
выберите **прежнюю папку** PulseDeck, не удаляя старую установку.

Это **веб-установщик**, пока в сборку не включён проверенный архив Electron.
При первом запуске он получает закреплённую среду Electron и проверяет её SHA-256;
затем показывает основной мастер. На этапе «Компоненты» мастер получает yt-dlp
и пару FFmpeg/FFprobe с проверкой SHA-256, распаковкой и пробным запуском версии.
Они не встроены в EXE, но их установка теперь обязательна до экрана успеха.
Уже проверенные полные версии той же или более новой версии повторно не качаются.
При ошибке загрузки Setup не заменяет код приложения и не объявляет установку
успешной. Интернет, свободное место и запись в выбранную папку необходимы.

Новая установка отделяет программу от пользовательских данных. При переходе
старые `music` и `data` **не перемещаются**: сохраняется карта путей, включая ссылки
на обложки и закрытые плейлисты. Изменённые языковые JSON/SVG копируются в
пользовательские языки перед заменой приложения. См. [данные и миграция](docs/storage.md).

Установщик/помощник **не подписаны Authenticode**. Подписанный канал обновлений —
другая проверка, он не устраняет предупреждения Windows. Программа не отключает
SmartScreen, антивирус, UAC или игровые средства защиты. Интерактивные сценарии
Windows нужно принять по [чек-листу](docs/release-checklist.md) перед публичным релизом.

## Сборка из чистого клона

Нужны Go 1.23+, Python 3.10+, Node.js 22+ для тестов. В приложении и установщике
нет скачиваемых npm-зависимостей: криптография и транспорт используют Node builtins,
движок установки — Go standard library. `app/assets/native/*.exe`, `app/licenses`
и встроенный payload генерируются при сборке, готовый EXE не нужен на входе.

```sh
node --test tests/*.test.js
node tools/audit-i18n.js
python tools/build-release.py
(cd native && go test -race ./...)
(cd installer/engine && go test -race ./...)
python tools/package-source.py
```

Результат — `dist/PulseDeck-Setup-2.9.2.exe`. Сборка не загружает среду и инструменты
из сети. Для добавления среды офлайн:

```sh
python tools/build-release.py --runtime-zip /outside/repo/electron-v44.4.1-win32-x64.zip
```

Хеш архива должен точно совпасть с `installer/runtime.json`. Это убирает загрузку
Electron, но для первой установки FFmpeg/FFprobe и yt-dlp всё ещё нужен интернет.

Для визуальных тестов установите `tests/requirements.txt` и Chromium:
`python tools/run-browser-tests.py`. Подробности, платформенные границы и контроль
встроенных файлов — в [docs/building.md](docs/building.md).

## Структура

| Путь | Назначение |
|---|---|
| `app/` | Electron main/preload, renderer, локализация и ресурсы |
| `app/online/`, `app/shared/online-search.js` | Адаптеры, пагинация, проверки, ранжирование |
| `app/discovery/` | Локальная история и объяснимые рекомендации |
| `app/updates/` | Подписанные манифесты, загрузка, установка и компоненты |
| `installer/ui/` | Отдельный изолированный HTML-интерфейс установщика |
| `installer/engine/` | Go bootstrap и транзакционное обслуживание Windows |
| `native/` | Исходники игрового помощника |
| `tests/` | Регрессии и небольшие тестовые фикстуры, не личная библиотека |
| `tools/` | Сборка, аудит, подпись, упаковка чистых исходников |
| `licenses/`, `CREDITS.md` | Сторонние лицензии и происхождение ресурсов |
| `docs/history/` | Исторические заметки, не действующий код установки |
| `.github/workflows/` | Проверки и создание **черновика** официального релиза |

Подробные результаты/скриншоты тестов, музыка, кэш, установщики, приватные ключи
и зависимости не должны попадать в Git. `.gitignore` и упаковщик исключают их.
Тестовые скриншоты являются CI-артефактами, а не исходниками.
