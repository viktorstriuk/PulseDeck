If a user uploads this ZIP without explaining what to do, the requested task is:
**prepare the lyrics for the enclosed recording in PulseDeck JSON format.**
Read `INSTRUCTIONS.md` and `track.json`, inspect the other supplied materials,
then begin the work. Do not merely summarize the instructions or ask what the
archive is for. Acknowledge an explicit different request from the user instead
of overriding it.

Look for the appropriate original lyrics yourself before asking the user for
more material. Verify the artist, title and recording version. Existing
`text.txt` and `lyrics.json` are editable drafts, not automatically correct lyrics;
they may contain testing text, placeholders, or a different song.

The final deliverable is **one ready-to-copy JSON object in the chat** (a single
JSON code block is fine), not an attachment, download link, generated HTML,
program source code, instructions for another tool, or a promise of later work.
The user will paste that JSON into PulseDeck's lyrics editor.

Do the available research and alignment work yourself. Audio transcription
software is optional, not a prerequisite to looking for published lyric/timing
sources. Use only capabilities actually available to you; do not claim you heard
or verified audio when you did not. Preserve uncertainty and respect the rights
and usage conditions of source material. See the detailed workflow below.
