# Языки PulseDeck 2.8.0 / PulseDeck language packs

Штатные каталоги находятся в `app/languages` (в установленной программе —
`resources/app/languages`). Для изменения/добавления языка используйте
**пользовательскую** папку `%APPDATA%\PulseDeck\languages`, которую открывает
**Настройки → Язык приложения → Открыть папку languages**. Частичные сообщения
из неё перекрывают штатные сообщения того же языка; новые ключи из обновления
остаются доступны. Скопируйте туда штатный `en.json` или `ru.json` для редактирования.
Пользовательские JSON и icons сохраняются при замене программы.

## Добавление или редактирование языка

Скопируй `en.json` в новый файл, например `de.json`. В `meta` измени код,
отображаемое имя, локаль форматирования и имя иконки. Переводи значения
`messages`, но не меняй ключи. Для минимального пробного пакета достаточно:

```json
{
  "meta": {
    "code": "de",
    "name": "Deutsch",
    "locale": "de-DE",
    "direction": "ltr",
    "icon": "de.svg"
  },
  "messages": {
    "SettingsButton": "Einstellungen"
  }
}
```

Это только пример формата; немецкий пакет в поставку не включён. Положи
собственную иконку в `icons/de.svg`. Без иконки язык тоже работает. Новые файлы
и сохранённые изменения JSON обнаруживаются автоматически. Кнопка
«Перечитать языки» принудительно обновляет список, переводы и иконки.

Имя файла без `.json` — идентификатор языка. `meta.code` можно опустить; если
он указан, он должен совпадать с именем файла. Рекомендуются коды `de`, `pt-BR`
и подобные. Разрешены латинские буквы, цифры, `_` и `-`, первый символ — буква,
максимум 64 символа. Расширение — именно `.json`. `meta.name` — непустое
отображаемое имя до 100 символов. `locale` используется для чисел, дат и
множественного числа; некорректная локаль безопасно заменяется английской.
`direction` — `ltr` или `rtl`. `icon` — только имя SVG внутри `icons`, не путь.

JSON сохраняется в UTF-8; BOM допустим. Комментарии и завершающие запятые не
поддерживаются. Каталог ограничен 2 МиБ, отдельная SVG — 256 КиБ. Повреждённый
каталог пропускается с пояснением в настройках, а не останавливает приложение.
Ссылки на внешние пути, символьные ссылки и исполняемая HTML-разметка не нужны:
иконки загружаются как изображения, имена языков и переводы — как обычный текст.

## Единственная цепочка поиска

`I18n.t('SettingsButton')` ищет значение в выбранном JSON, затем **только** в
`en.json`. Если подходящего значения нет в обоих файлах, показывается
`SettingsButton`: ключ без обрамляющих пробелов и кавычек. Не выполняется
поиск в русском или других установленных языках; нет встроенного запасного
текста. Пустое, нестроковое или неподходящее значение также считается пропуском.

Удаление выбранного пакета не стирает предпочтение пользователя: до возвращения
файла используются английские строки и показывается предупреждение. При
добавлении неполного пакета английский используется только для отсутствующих
ключей. Изменение `en.json` изменяет и запасные переводы всех неполных пакетов.

## Параметры и множественное число

Оставляй параметры `{value1}`, `{detail}`, `{count}` и другие в переводе.
Их можно переставлять, но имена должны совпадать с английским каталогом.
Значения не исполняются как HTML или JavaScript.

```json
{
  "TrackCount": {
    "one": "{count} трек",
    "few": "{count} трека",
    "many": "{count} треков",
    "other": "{count} трека"
  }
}
```

Форма выбирается по `count` и локали самого каталога. Допустимы `zero`, `one`,
`two`, `few`, `many`, `other`; для английского обычно нужны `one` и `other`.
Строки `Installer*` применяются установщиком и могут содержать параметры Go
`%s`, `%d`, `%v`, `%.1f` и `%%`: их количество и типы тоже нужно сохранять.

Количество ключей проверяет `node tools/audit-i18n.js`; ru/en синхронизированы. Технические строки
протоколов, пути, CSS-селекторы, имена клавиш и сами ключи не являются переводами.
Названия треков, артистов и пользовательских плейлистов, импортированный текст
песен и заметки пользователя остаются данными и не переводятся автоматически.

## Обновление и разработка

Язык хранится вместе с настройками пользователя, а не в каталоге. Переключение
не перезапускает плеер, не пересоздаёт редактор и не сохраняет черновик вместо
пользователя. Новые системные подписи не записываются в теги аудио.

Установщик 2.8.0 переносит старые пользовательские JSON/SVG из заменяемого
`resources/app/languages` в profile/languages, предварительно создавая резервные
копии. Уже существующие overrides не перезаписываются повторной миграцией.
Не редактируйте только bundled-каталоги после перехода: обновление заменяет код;
пользовательскую папку оно сохраняет.

Для новых подписей используй `I18n.t(key, params)` в обычном тексте,
`I18n.h(key, params)` в HTML-шаблонах, `data-i18n` для статической разметки или
`I18n.setText(node, () => I18n.t(key, params))` для живой подписи. Ошибки создавай
как `I18n.error(key, params)`. Для вложенного системного названия используй
`I18n.msg(key, params)`, а не заранее переведённую строку. Не передавай в эти
механизмы пользовательские названия в качестве ключей.

Аудит без установки npm-зависимостей: `node tools/audit-i18n.js` из корня
исходников. Отчёт и места использования ключей появляются в
`test-results/2.8.0`. Парсер Acorn поставляется с лицензиями в `tools/vendor`.

## English

Copy the built-in `en.json` into your user languages folder as a new language-code
JSON file, change its `meta`, translate
message values, and put the named SVG in `icons`. The app discovers packs and
edits without restart; Settings → Application language also offers a reload
button and the exact folder location. Lookup is strictly selected pack →
`en.json` → cleaned key. Keep interpolation names and installer format specifiers.
User-authored text and metadata are never treated as translation keys.
