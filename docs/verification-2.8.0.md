# Проверка подготовленной версии 2.8.0

23 сентября 2026. Проверено в Linux x64: Node.js 22.16.0, Go 1.23.2,
Python 3.13.5, Playwright 1.57.0 и Chromium 144.0.7559.96.

- Node.js: **416/416**, без пропусков/отмен, включая 80 новых проверок транспорта,
  подписи, обновлений, компонентов, IPC, публикации и путей хранения.
- Chromium: **727/727** в 13 наборах, включая 119 новых проверок реального renderer
  приложения и HTML-установщика. IPC имитируется, Windows не эмулируется.
- Go-движок установки: **21 тест верхнего уровня**, **29 вместе с вложенными
  сценариями**, `-race`, без ошибок. Native-помощник: **22 верхнего уровня**,
  **35 вместе с подслучаями/seed**, `-race`, без ошибок. Windows-специфические
  тестовые бинарники успешно кросс-компилируются, но здесь не выполнялись.
- Аудит RU/EN: **1 799 ключей в каждом**, ошибок проверки нет. Оставшиеся 30 ASCII
  кандидатов просмотрены: CSS-селекторы/классы, имена процессов, метаданные и
  технические заголовки, а не новые надписи интерфейса.
- Все **207** файлов встроенного payload (**201 app + 6 installer/ui**) извлечены
  без запуска EXE, проверены по SHA-256 и сопоставлены с деревом сборки.
- EXE: Windows AMD64, GUI subsystem, не консольное приложение. Чистый исходный ZIP
  распакован отдельно и пересобран без сети/старого EXE: результат побайтово совпал
  при одинаковом toolchain. Это не обещание совпадения при другой версии Go.
- PNG MusheP и link.svg побайтово равны предоставленным файлам. Шрифтовых файлов,
  приватных ключей, результатов прогонов и исполняемых файлов в исходном ZIP нет.

## Границы результата

Официальный GitHub-репозиторий и публичный ключ в этой поставке **не настроены**.
Продукционного приватного ключа не создавали. GitHub Actions, реальные Releases,
полная установленная Windows-цепочка обновления/перезагрузки, Win32-прозрачность,
SmartScreen/UAC и RTSS в игре здесь не запускались. Автоматические проверки
сбоя/отката выполнялись на временной файловой системе, а сетевые сценарии — с
детерминированным тестовым транспортом. Это не независимый security-аудит.

Установщик не подписан Authenticode и не содержит Electron-архив: при первой
установке потребуется сеть. Закреплённые runtime/tool hashes унаследованы от
предоставленной 2.7.1; архивы upstream заново не скачивались в этой среде.

Перед публичным стабильным каналом обязательна приёмка по
[docs/release-checklist.md](release-checklist.md). Полные логи/скриншоты выдаются
как отдельное свидетельство проверок, а не засоряют дерево исходников.
