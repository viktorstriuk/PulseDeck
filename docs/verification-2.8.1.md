# Проверки PulseDeck 2.8.1

База: предоставленный архив 2.8.0. Проверки выполнены 24 сентября 2026 года
в Linux-контейнере с Node.js 22, Go и Chromium. Версии приложения, интерфейса
установщика и игрового помощника согласованы: 2.8.1.

а IPC и сетевые ответы предоставляются изолированными тестовыми мостами.
Это не автоматизация работающего Windows EXE.

## Что проверяет новая часть

Языковой список: данные из метаданных JSON, флаги, выбор, фокус, стрелки,
Home/End, Enter/Space, Tab, Escape, поиск по набранным буквам, закрытие по клику
снаружи. Тестовый третий язык появляется без добавления RU/EN-ветки в UI;
частичный перевод использует английский запасной текст. Повреждённая иконка
не блокирует выбор. Длинный список прокручивается. Имя пакета с HTML остаётся
текстом. При установке список блокируется, выбранный код передаётся движку.

Системная тема проверена в CSS при светлом и тёмном `prefers-color-scheme`,
включая изменение темы без потери выбранного языка. Мастер, выбор папки, прогресс
и результат проверены при 1020x742 и 800x600, RU/EN. В блоке автора проверены
отсутствие свечения/движения, компактная высота, пять ссылок, розовый Pro,
полужирный контекст чата и безопасное обновление форматирования при смене языка.
Скриншоты осмотрены отдельно после завершения переходных анимаций.

Миграция каталогов проверена на известных stock-отпечатках, изменённых пользователем
значениях, дополнительных ключах/языках, точных резервных копиях, повторном запуске,
повреждённых каталогах, символьных ссылках и конфликте резервной копии. Проверены
ключи и параметры до/после редактуры. Пунктуация пользовательского текста сохраняется.

Выбор языка установки проверен через общий JS-алгоритм, фактический main.js Setup
в VM-мосте и Go-функции записи профиля. Проверены приоритет UI-языков, явный код,
английский запасной язык, сохранение неизвестных полей и точных целых чисел,
legacy-настройки, параллельное редактирование профиля, резервные копии, повреждённый
профиль и опасные пути. Установка в фоне не заменяет выбранный язык на системный.

## Редактура и поддержка тестов

Проверены два исходных каталога по 1 799 ключей. Выполнена смысловая редактура
175 пар RU/EN, а также общая проверка/нормализация пунктуации. В существующих
ключах изменены 584 русских и 568 английских значений; добавлено 9 ключей.
URL, параметры, версии, данные песен и тексты лицензий не нормализуются в runtime.

В первом регрессионном прогоне были устаревшие проверки прежних формулировок
(например, «Я—А», «fallback» и «Убрать их из избранного»). В проверках зафиксированы
новые намеренные тексты; поведенческие проверки удаления, сохранения и геометрии
не отключались. Итоговый прогон целиком успешен. Отладочные первые скриншоты и
промежуточные ошибки не включены в итоговый архив доказательств.

## Сборка и границы проверки

Собран Windows x64 PE32+ GUI установщик. Извлечены и проверены 212 файлов:
205 `app/` и 7 `installer/ui/`. Размеры и SHA-256 совпадают с манифестом,
а содержимое побайтово совпадает с рабочим деревом. Итоговый внешний отчёт
выпуска также содержит результат пересборки из очищенного ZIP.

Не выполнены интерактивный запуск установщика на Windows, проверка Windows UI
language API/нативного splash на реальной системе, RTSS в игре и установка
обновления между двумя настоящими GitHub Releases. Такие проверки нельзя
заменить просмотром в Chromium или Linux Go-тестами. Windows-ветки проходят
кросс-компиляцию, а поведение в реальной системе остаётся этапом приёмки.

Официальный репозиторий и ключ не заданы. Проверка обновлений приложения не
выполняет сетевые запросы к ненастроенному источнику. Setup не подписан
Authenticode, среда Electron не включена в EXE, для её получения может быть
нужен интернет. Поздняя обрезка YouTube не менялась и всё ещё может создать
дополнительный файл из исходной онлайн-ссылки.

## Повторение

```sh
node --test --test-timeout=180000 --test-concurrency=4 tests/*.test.js
node tools/audit-i18n.js
python tools/build-release.py --payload-only
(cd installer/engine && go test -race -count=1 -json ./...)
(cd native && go test -race -count=1 -json ./...)
python tools/run-browser-tests.py
python tools/build-release.py
python tools/extract-embedded.py dist/PulseDeck-Setup-2.8.1.exe /outside/repo/extracted
python tools/package-source.py
```

Машинные результаты и скриншоты находятся в отдельном архиве
`PulseDeck-2.8.1-test-evidence.zip`, не в исходниках.
