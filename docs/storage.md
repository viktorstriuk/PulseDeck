# Данные, установка и восстановление

Карта путей — `%APPDATA%\PulseDeck\storage.json`, schema 1. В ней фиксируются
абсолютные `music`, `data`, `tools`, `languages` и необязательный `legacyRoot`.
Повреждённая существующая карта вызывает ошибку: приложение не создаёт молча
новую пустую библиотеку вместо старой.

| Данные | Новая установка Windows |
|---|---|
| Программа | `%LOCALAPPDATA%\Programs\PulseDeck` по умолчанию |
| Настройки | `%APPDATA%\PulseDeck\settings.json` |
| Музыка | `%USERPROFILE%\Music\PulseDeck` |
| Тексты песен, оформление, данные библиотеки | `%LOCALAPPDATA%\PulseDeck\data` |
| Дополнительные/изменённые языки | `%APPDATA%\PulseDeck\languages` |
| Версии FFmpeg/FFprobe/yt-dlp | `<папка установки>\components` |
| Загрузки приложения | `%LOCALAPPDATA%\PulseDeck\updates` |
| Chromium profile | `%LOCALAPPDATA%\PulseDeck\chromium` |
| Runtime cache Setup | `%LOCALAPPDATA%\PulseDeck\setup-cache` |

С 2.9.1 исполняемые компоненты, их архивы загрузки и временная распаковка
находятся только внутри выбранной папки установки:

```text
<папка PulseDeck>/
  components/
    index.json
    downloads/
    ffmpeg/<версия>/ffmpeg.exe
    ffmpeg/<версия>/ffprobe.exe
    ytdlp/<версия>/yt-dlp.exe
```

У каждой установленной версии есть `receipt.json`. Файлы из PATH, внешнего
AppData или другой установки не используются. Старая `<та же папка>/tools`
поддерживается для совместимости, если путь не проходит через символьную ссылку.
Неполная пара FFmpeg/FFprobe считается отсутствующей и может быть восстановлена.

Первый запуск 2.9.1 меняет только `storage.tools`, предварительно сохраняя
`%APPDATA%/PulseDeck/backups/before-components-local-2.9.1.json`. Старые внешние
бинарники не копируются и не удаляются: Setup получает новые проверенные файлы.
Музыка, данные, настройки и пути языков остаются прежними. Это **не перевод всего
профиля в portable-режим**. Кэш среды bootstrap, Chromium и данные пользователя
по-прежнему используют перечисленные выше системные папки; рабочая среда Electron
и native-помощник находятся в папке установленного приложения.

При переходе с 2.7.1 музыка и data остаются рядом со старой программой; установщик
записывает эти пути **до** замены resources/app. Он не переименовывает треки и не
пытается перемещать шифрованные папки. Старые settings сохраняются в profile;
резервная копия создаётся перед новой схемой/применением обновления. Локальная
запись `LOCALAPPDATA/PulseDeck/installation.json` помогает следующему Setup найти
выбранное место установки, она не отправляется в сеть.

Штатные каталоги `resources/app/languages` остаются частью выпуска. Пользовательские
overrides в profile/languages объединяются по ключам поверх штатных. Сначала
выбранный язык, затем английский, затем очищенный ключ. Новые штатные ключи не
пропадают из-за частичного override. Перед миграцией старых переводов создаётся
резервная копия; повторный запуск не затирает уже перенесённые пользовательские
файлы. Кнопка «Открыть папку languages» открывает **пользовательскую** папку.
Скопируйте в неё штатный JSON для полного редактирования или добавьте частичный
messages; в поставку исходников идут только штатные ru/en. Новые JSON подхватываются
наблюдателем, отсутствие/ошибка пакета отображается в настройках.

## Транзакция программы

Движок допускает только явный список файлов Electron/PulseDeck. `music`, `data`,
`tools`, посторонние пользовательские файлы и весь resources целиком не удаляются.
Stage и backup создаются на том же диске; эксклюзивная блокировка не допускает
одновременные обновления, установленный процесс должен закрыться. Проверяются
опасные пути и символические ссылки в целевом пути/назначениях.

Каждый rename имеет fsync-журнал намерений. В случае ошибки выполняется обратная
последовательность, возвращается предыдущий receipt. При повторном старте движка
незавершённая транзакция восстанавливается, а уже committed журнал не откатывает
успешную установку. Предыдущий код остаётся в backup. Это recovery-протокол,
а **не обещание абсолютной атомарности** всей установки при любом отказе диска.
Сбой питания/диска, права, антивирус и junction-поведение проверяются отдельно на
Windows. Не удаляйте stage/backup вручную, пока журнал не завершён.

## Удаление

`Uninstall PulseDeck.exe` использует тот же собственный интерфейс. Удаляются
только принадлежащие программе пути из проверенного receipt, ярлыки и запись
установки. Музыка, карта библиотеки, profile, overrides, тексты и рабочие копии
сохраняются. Старые rollback-backup намеренно не стираются как личные данные.
Небольшая временная копия работающего uninstaller может остаться в системной
Temp до обычной очистки Windows — он не пытается удалить исполняемый собственный
образ во время работы.

Для полного личного сброса сначала сделайте резервную копию всех путей storage.json,
включая скрытые файлы. Не удаляйте всю прежнюю папку установки, предполагая, что
там уже нет музыки: миграция сохраняет её расположение.

## Язык установки и миграция формулировок 2.8.1

Обычный Setup начинает с поддерживаемого языка интерфейса Windows, а не языка
дат и валют. Явный `--language` имеет приоритет. Мастер передаёт выбранный код
движку; после успешной установки тот меняет только `language` в profile/settings.
Перед заменой бинарников существующий профиль проверяется, повреждённый JSON
не заменяется пустыми настройками. Перед сохранением читается свежая версия
профиля, чтобы не стереть изменения, сделанные во время загрузки Setup.
Точные старые байты сохраняются в
`%APPDATA%/PulseDeck/backups/before-setup-language-<timestamp>.json`.
При `--apply` обновление сохраняет текущий язык приложения и не записывает
системный язык поверх пользовательского выбора.

В 2.8.0 полный старый штатный каталог мог оказаться в пользовательской папке
`languages` и закрывать новые формулировки. На первом старте 2.8.1
`app/i18n/stock-upgrade.js` сравнивает значения с отпечатками штатных поставок
2.7.1 и 2.8.0. Удаляются только точно совпавшие штатные значения; реальные
изменения, новые ключи, метаданные и дополнительные языки остаются.

До очистки каталог копируется байт-в-байт в соседнюю папку
`language-backups/copy-2.8.1/`. Маркер `.stock-copy-2.8.1` отмечает законченные
языки. Миграция не повторяет очистку после последующей осознанной правки.
Повреждённые, слишком большие или ссылочные файлы остаются нетронутыми;
ошибка резервного копирования не разрешает удаление переводов. Отпечатки
не позволяют отличить текст, специально возвращённый к старому штатному
значению, от неизменённого stock-каталога: поэтому точная копия сохраняется
и её можно использовать для восстановления. После миграции такое значение
можно задать заново, оно больше не будет автоматически очищено.
