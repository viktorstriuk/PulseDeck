## Что действительно проверено

Node-тесты выполняют файловые операции в изолированных временных каталогах:
публичные sidecar-правки, стабильность идентификатора и аудиохеша, приватные
зашифрованные правки и сохранение аудиопотока, конфликты ревизий, ZIP/TAR/TGZ,
небезопасные пути/ссылки/CRC/размеры/повреждённый gzip, отмену, изменившийся источник,
коллизии имён, импорт локальных текстов. Отдельный сквозной тест вызывает настоящий
main IPC → importer → publisher → enrichment → scanner: до подтверждения библиотека
пуста, после подтверждения импортирован трек с восстановленными именами, его
оригинал и аудиобайты не изменены. Electron/Windows API в этом тесте подменены.

Сетевые сервисы, время ответа, отмена и ошибки проверены на контролируемых ответах.
Это проверка собственного кода, не подтверждение текущей работоспособности всех
сторонних сайтов. Тесты CAA проверяют разрешённые редиректы и отдельную трактовку
404/сбоя, тесты LRCLIB — ограничение ответа и строгий выбор синхронизированных
текстов. Смена метаданных во время поиска не позволяет записать устаревший результат.

Браузерные сценарии запускают настоящий renderer в Chromium. Для новых меню и
сетей используется детерминированный IPC; отдельный существующий набор текстов
работает с настоящим main/backend, шифрованием, файлами, ZIP и потоками через
изолирующий мост. Windows API, нативное перетаскивание и аудиоустройства не заменяют
реальный Windows-прогон.

Визуально просмотрены обложки, импорт, действия плейлиста и ссылка в поиске.
В новом наборе проверены русский/английский интерфейс, океанская/светлая/песочная
темы и окна 800×600, 1024×768, 1440×900. На иллюстрациях тестовые треки и иконки
PulseDeck вместо обложек музыкальных альбомов.

## Найдено и исправлено во время работы

Первый общий браузерный прогон обнаружил русскую подпись скрытого drop-overlay
при английском языке: она переведена на реактивные привязки локализации. Проверено
переключение языка открытого подтверждения без потери выбранных улучшений.

В старом тестовом IPC-мосте хранился единственный подписчик на канал блокировки,
поэтому второй обработчик заменял первый. Мост приведён к реальному многоподписному
контракту preload. Логи первого прогона сохранены отдельно; после исправления
полностью повторены все 18 наборов, включая реальное очищение приватных текстов.

Во время разработки также исправлены ранний UUID для тестового контекста,
позиционирование панели у скрытого меню, гонка окончания короткой очереди,
проверка смены метаданных при фоновой записи текста, ограничение повторных
сканирований большой библиотеки и обработка ошибки всех источников обложек.

## Воспроизведение

Из корня исходников:

```sh
node --test tests/*.test.js
python tools/run-browser-tests.py
node tools/audit-i18n.js
python tools/build-release.py
(cd native && go test -race -count=1 ./...)
(cd installer/engine && go test -race -count=1 ./...)
python tools/extract-embedded.py dist/PulseDeck-Setup-2.9.2.exe extracted
```

Для браузерного прогона нужны Python Playwright и Chromium. Перед тестами
installer/engine сначала создаётся payload командой build-release; без него
Go embed не имеет входного файла. Сборка требует Python и Go; Windows EXE в среде
проверки не запускается. Архив исходников не содержит бинарников, шрифтов,
пользовательской музыки, профиля и секретов.

## Что ещё необходимо проверить на Windows

1. Чистая установка и обновление 2.9.1 в ту же папку; компоненты при работающем
   интернете, отказе сети и пути с кириллицей. Проверка на обычной учётной записи.
2. Настоящее перетаскивание из Explorer: файлы, вложенные папки, ZIP/TAR/TGZ,
   отмена до подтверждения, остановка очереди, одноимённые файлы, отсутствие места.
3. Загрузка собственного PNG/JPEG/WebP через nativeImage; сохранение обложек,
   названий и исполнителей после перезапуска; избранное, порядок, тексты и звук.
4. Реальные запросы включённых музыкальных источников, MusicBrainz/CAA и LRCLIB;
   сетевые отказы, пустые ответы, отмена, смена запроса и проверка выбранной версии.
5. Ссылка на одиночный трек с локальным yt-dlp, показ оригинала и альтернатив;
   отсутствие инструмента и ссылки на плейлист должны давать понятный отказ.
6. Закрытый плейлист: смена обложки без прерывания звука, блокировка во время
   фонового запроса и отсутствие приватных полей после закрытия.
7. DPI 100/125/150/200%, клавиатура и экранный диктор, разные аудиоустройства,
   антивирус/SmartScreen и нативные файловые диалоги.

**Интерактивная Windows-установка и живые сервисы здесь не проверены.**
Установщик не подписан Authenticode, Electron/yt-dlp/FFmpeg не включены в EXE;
для первой установки нужен интернет. Поддерживаются ZIP stored/deflate,
TAR/TAR.GZ/TGZ, но не RAR/7z/ZIP64/зашифрованные/вложенные архивы.
