# PulseDeck 2.9.3-beta.2

## Проверка настоящего обновления beta.1 → beta.2

Эта предварительная сборка создана специально для проверки полного пути обновления
из уже установленной PulseDeck 2.9.3-beta.1 через встроенный beta-канал.

- Пользовательские функции намеренно не менялись относительно beta.1.
- После публикации beta.1 с включёнными «Предварительными версиями» должна обнаружить
  2.9.3-beta.2 как более новую версию.
- PulseDeck должен скачать установщик из официального GitHub Release, проверить
  подписанный Ed25519-манифест, размер и SHA-256 файла перед запуском установки.
- Проверяем сохранность библиотеки, настроек, плейлистов, компонентов и пользовательских
  данных после перезапуска и обновления.
- Stable-feed не создаётся; стабильный канал эту версию автоматически не получает.

Если этот переход проходит на реальной Windows-машине, следующая цель — подготовка
стабильной 2.9.3 после финальной ручной проверки.

Установщик пока не подписан Authenticode; предупреждения Windows SmartScreen не
связаны с подписью внутреннего update-feed.
