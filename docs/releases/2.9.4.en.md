# PulseDeck 2.9.4

## Covers and library

- Renaming artists and tracks works with both Save and Enter. Closing editors no longer focuses and opens search.
- Removed artificial cover file-size, resolution and 1200-pixel downscaling limits. Original files are retained without transcoding; actual decoding still depends on supported formats and device resources.
- Choose or drop images, GIFs and Chromium-compatible videos (such as MP4 and WebM) in the cover picker or onto a track. Videos are muted, paused offscreen and while hidden; reduced-motion mode displays a still video frame.
- Visible loading feedback, progressive results and continued loading while scrolling. Load more and retry remain available. Sources determine the number of results, not one fixed batch.
- Catalog lookup searches recordings and their releases. Automatic matching tolerates modest metadata and duration differences, retries alternative artwork after decoding errors, and can fall back to same-artist artwork. Synced-lyrics search no longer stops on a plain-only exact match.
- Existing artwork, synced lyrics, suppression and manual lyric edits are preserved. Additional actions appear as soon as eligibility is known; counts update progressively.

## Interface and updates

- Lyrics are revealed after the saved background is ready, without briefly showing an unrelated gradient.
- Removed duplicate search source chips and automatic filter-field population. Track trimming uses the scissors icon.
- Configure automatic update checks in minutes, hours or days, with input normalization, interval-preserving unit conversion and safe long timers.
- Existing signed updates and the public key are unchanged. This version uses the stable feed. Audio component updates remain separate.
