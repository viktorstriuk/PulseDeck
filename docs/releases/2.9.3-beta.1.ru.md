# PulseDeck 2.9.3-beta.1

## Первый prerelease официального канала

Это первая предварительная сборка PulseDeck, выпущенная через официальный
репозиторий `viktorstriuk/PulseDeck`. Она нужна для проверки реальной цепочки
обновления на Windows перед публикацией стабильной 2.9.3.

- В приложение встроены адрес официального репозитория и публичный Ed25519-ключ.
- Манифест beta-обновления подписывается отдельным закрытым ключом в защищённом
  GitHub Environment; закрытый ключ не входит в исходники и установщик.
- Пререлиз создаёт только `pulsedeck-update-beta.json`, поэтому пользователи
  стабильного канала не должны получить эту версию автоматически.
- yt-dlp и FFmpeg/FFprobe продолжают обновляться независимо по проверяемым
  источникам издателей; репозиторий приложения их не блокирует.
- CI теперь полностью проверяет Node.js, локализацию, сборку Windows x64, Go с
  race detector и Chromium UI-набор перед созданием release draft.
- Исправлена нестабильность тестов системной темы, drag-приоритета источников и
  resize-зоны игрового оверлея на GitHub-hosted runner.

## Что проверяем вручную

После публикации prerelease нужно установить 2.9.3-beta.1 на Windows и убедиться,
что библиотека, настройки, компоненты и пользовательские данные сохранились. Затем
будет выпущена следующая beta-сборка, чтобы проверить обнаружение обновления,
скачивание, проверку Ed25519/SHA-256, перезапуск и установку через сам PulseDeck.

Установщик пока не подписан Authenticode; предупреждение Windows SmartScreen не
связано с криптографической подписью внутреннего update-feed.
