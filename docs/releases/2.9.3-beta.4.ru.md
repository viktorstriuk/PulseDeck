# PulseDeck 2.9.3-beta.4

## Контрольная сборка для встроенного обновления

Эта prerelease-версия создана специально для финальной end-to-end проверки механизма
обновлений после исправления сетевого транспорта в 2.9.3-beta.3.

Функциональность приложения намеренно не менялась относительно beta.3. После публикации
beta.4 установленная 2.9.3-beta.3 с включёнными предварительными версиями должна сама:

- обнаружить новую версию через подписанный `pulsedeck-update-beta.json`;
- скачать установщик из официального GitHub Release;
- проверить подпись Ed25519, размер и SHA-256;
- запустить Setup только после подтверждения пользователя;
- после установки и перезапуска показать версию 2.9.3-beta.4.

Stable-feed для этой версии не публикуется. Пользователи стабильного канала beta.4
автоматически не получают.

Установщик пока не подписан Authenticode; подпись внутреннего update-feed и SHA-256
проверяются независимо от Windows SmartScreen.
