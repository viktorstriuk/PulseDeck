# PulseDeck 2.8.1

Переработаны формулировки в русских и английских каталогах: меньше повторов,
конкретные действия и полезные пояснения. Убраны конечные точки и длинные тире
в штатном интерфейсе. Пользовательские имена, заметки и тексты песен не изменяются.

В «О PulseDeck» обновлены подписи SVG Repo и Font Awesome Brands. Блок MusheP
компактнее: PNG без свечения и наклона, авторская подпись и строка исполнения
с розовым Pro и выделенным контекстом чата. Форматирование собирается безопасными
DOM-узлами; переводы не могут вставлять HTML.

Установщик использует новый заголовок, предоставленный user-off.svg и список
языков с флагами вместо отдельных RU/EN-кнопок. Языки обнаруживаются из каталогов,
доступны клавиатура, прокрутка и запасное отображение без иконки. Обычный запуск
выбирает язык интерфейса системы; при успешной установке выбранный язык сохраняется
для приложения. В автоматическом обновлении текущий язык приложения сохраняется.

Светлая и тёмная темы мастера следуют системе. Стартовое графическое окно использует
ту же системную настройку Windows. Геометрия проверена при 800x600 и 1020x760.

Старые штатные переводы, скопированные в пользовательскую папку в 2.8.0, больше
не закрывают новую редакцию. Миграция знает хеши поставок 2.7.1/2.8.0, создаёт
резервную копию и сохраняет изменённые значения, названия пакетов и новые языки.

Официальный репозиторий и публичный ключ ещё не заданы. Подключение канала,
два настоящих GitHub Releases и интерактивная Windows-приёмка остаются отдельным
этапом. Это неподписанный Authenticode веб-установщик; может требоваться интернет.
Перед обновлением сохраните music, data со скрытыми файлами и профиль PulseDeck.
