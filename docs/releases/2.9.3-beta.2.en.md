# PulseDeck 2.9.3-beta.2

## Real beta.1 → beta.2 in-app update validation

This prerelease exists specifically to validate the complete update path from an
already installed PulseDeck 2.9.3-beta.1 through the built-in beta channel.

- No intentional user-facing feature changes were made relative to beta.1.
- With prereleases enabled, beta.1 should discover 2.9.3-beta.2 as a newer version.
- PulseDeck should download the installer from the official GitHub Release and verify
  the signed Ed25519 manifest, file size, and SHA-256 before installation.
- The acceptance check covers library, settings, playlists, managed components, and
  user data surviving restart and upgrade.
- No stable feed is produced, so stable-channel users should not receive this build.

If this transition succeeds on a real Windows machine, the next target is the stable
2.9.3 release after final manual acceptance.

The installer is not Authenticode-signed yet. Windows SmartScreen warnings are
separate from the cryptographic signature used by PulseDeck's internal update feed.
