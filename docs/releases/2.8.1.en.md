# PulseDeck 2.8.1

Revised the Russian and English interface copy: clearer actions, shorter helper
text and less repetition. Stock interface messages no longer end in full stops
or use long dashes. User names, notes and lyrics remain unchanged.

Updated SVG Repo and Font Awesome Brands descriptions. The MusheP card is compact,
with a static author PNG, the requested author statement and a separate execution
credit. The Pro label is pink, and the chat context is emphasized. Translation
slots use text nodes and explicitly allowed DOM elements, never raw HTML.

Setup now uses the revised headline, the supplied user-off.svg and a flag-and-code
language dropdown populated from the catalogs. Keyboard control, scrolling and
missing-flag fallback are supported. Normal setup starts in a supported system UI
language; a successful installation stores the selected language for PulseDeck.
Unattended updates preserve the current application language.

The main wizard follows the system light/dark theme. The native bootstrap reads
the same Windows app-theme preference. Browser layouts were checked at 800x600 and
1020x760. Actual Windows interactive acceptance remains a separate step.

A backed-up, one-time migration removes known old stock translation overrides from
2.7.1/2.8.0 without replacing actual edits or additional language packages.

The official repository and public key remain unconfigured. Real release-to-release
upgrade testing is still required. Setup has no Authenticode signature and may need
network access for the pinned Electron runtime. Back up music, data and the profile.
