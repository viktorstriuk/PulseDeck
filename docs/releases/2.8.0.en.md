# PulseDeck 2.8.0

Author/credits page, update center, signature/hash verification, managed media
tools, fully custom graphical installer and stable user-data locations.

The official channel becomes active only when the repository and public key are
configured before building. Older/unconfigured installations need one manual
transition. Close the application and back up music, data and the profile. The web
installer needs internet for its pinned runtime; FFmpeg/yt-dlp are provisioned separately.

See docs/release-checklist.md. Publishing is not a substitute for Windows acceptance.
