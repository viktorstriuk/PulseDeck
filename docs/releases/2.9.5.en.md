# PulseDeck 2.9.5

## Library and menus

- Library folders with independent All, Favorites, Downloads, Recent, artist and custom playlists. The existing layout stays unchanged until folders are created. Playlist editing exposes a left-side plus button and the familiar name, icon, color and gradient editor.
- Folder overview, animated entry with a compact back button, scoped counts and empty states. Playlist menus can move a playlist into a folder; folder menus can move every track from a chosen section, including All.
- Public audio files are physically moved within `music`. Existing destinations are never overwritten; collisions receive a free name. Audio bytes, track IDs, favorites, playlist references and accompanying files are retained. A journal supports pre-commit rollback and post-commit cleanup. Renaming changes the display name, not the physical directory. Only empty folders can be deleted.
- Folders organize a library; they are not access control. Custom protected playlists can be regrouped without decrypting them. Automatic transfers of protected system sections are blocked to avoid changing keys or disclosing contents. Explicit unprotection restores audio into the playlist’s current folder. Relocating a previously public copy updates protected-view references; folder conflicts are checked before any decryption.
- Remove from and Add to switch positions. Right-click a menu command to expose three-dot handles, then reorder vertically with the pointer or arrow keys. Ctrl+Z, Ctrl+Y and Ctrl+Shift+Z undo/redo moves, with immediate persistent saves. Escape exits editing.
- Right-click the bottom player's artwork for the current track menu. Edit track → Animate artwork appears for video artwork only and updates its check/X state without closing the menu or recreating artwork.
- Increasing/decreasing loudness sorting measures integrated loudness over the first 10 seconds with the managed FFmpeg component. At most two analyses run concurrently; cached results are invalidated when files change. Unknown results stay last. Playback volume and audio files are not modified.

## Lyrics

- Eight compact swatches: four variants derived from the actual cover palette, three fixed gradients, and the last manually selected/created gradient. Cover-derived choices are disabled rather than replaced with arbitrary colors when artwork is missing.
- A plain, easily clickable swap icon between gradient colors, without a backdrop, border or shadow.
- Choose an image, GIF or supported video from disk, or drop it onto the background preview/drop zone. Custom background is stored independently of album artwork. Cover mode is unavailable when the track has no real artwork.
- Private-track backgrounds are encrypted with lyrics data; streaming access is revoked on lock. Private palettes are not persisted in the global last-gradient preference.

## Presets and standalone player

- A dedicated Presets settings section: name, selection of any of nine sections, save, one-click apply, rename, overwrite and delete.
- Captures appearance including icon, standalone/game player, hotkeys, library view, language, playback, search and update-check preferences. Music, playlists, passwords and trusted update keys are excluded. Custom icons/backgrounds reference assets on the same computer; a preset is not a portable media archive.
- Applying a preset does not recreate the audio player. A rollback journal is written before changes, and hotkey registration conflicts produce warnings.
- Standalone progress is independent of both elapsed and remaining time labels.
- Position and size are saved after movement/resizing and before closure. Restore uses the matching monitor's full bounds, including its taskbar area, and supports secondary monitors with negative coordinates. A disconnected monitor falls back to a visible location.
- Windows receives consistent AppUserModelID, icon and relaunch properties. Icons are repaired only for shortcuts targeting the current PulseDeck.exe, including existing pinned links. PulseDeck does not pin itself or alter other applications' links.

## Release

Application, installer and native helper versions are **2.9.5**, with matching RU/EN notes. The update repository, Ed25519 public key, signature checks and SHA-256 verification remain unchanged. This is a stable version number. Produce the final installer through the existing release workflow after green CI; do not replace a published asset with a different local build.
