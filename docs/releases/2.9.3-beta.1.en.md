# PulseDeck 2.9.3-beta.1

## First prerelease of the official update channel

This is the first PulseDeck prerelease built from the official
`viktorstriuk/PulseDeck` repository. Its main purpose is to validate the real
Windows update path before publishing the stable 2.9.3 release.

- The application now ships with the official repository address and a pinned
  Ed25519 public key.
- The beta update manifest is signed with a separate private release key stored
  in a protected GitHub Environment; the private key is not part of the source
  tree or installer.
- Prereleases create only `pulsedeck-update-beta.json`, so stable-channel users
  should not receive this build automatically.
- yt-dlp and FFmpeg/FFprobe remain independent publisher-managed components and
  are not blocked by the application release repository.
- CI validates Node.js tests, localization, the Windows x64 build, Go race tests,
  and the Chromium UI suite before a release draft is created.
- GitHub-runner stability was improved for system-theme tests, source-priority
  dragging, and the game-overlay resize regression.

## Manual acceptance

After publishing this prerelease, install 2.9.3-beta.1 on Windows and confirm that
its library, settings, components, and user data survive the upgrade. A second
beta build will then be published to test in-app discovery, download, Ed25519 and
SHA-256 verification, restart, and installation end to end.

The installer is not Authenticode-signed yet. Windows SmartScreen warnings are
separate from the cryptographic signature used by PulseDeck's internal update feed.
