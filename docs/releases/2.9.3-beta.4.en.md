# PulseDeck 2.9.3-beta.4

## Control build for the in-app update path

This prerelease exists specifically for the final end-to-end update test after the live
network transport fix introduced in 2.9.3-beta.3.

Application functionality is intentionally unchanged from beta.3. Once beta.4 is
published, an installed 2.9.3-beta.3 with prereleases enabled should be able to:

- discover the new version through the signed `pulsedeck-update-beta.json`;
- download the installer from the official GitHub Release;
- verify the Ed25519 signature, exact size and SHA-256;
- launch Setup only after user confirmation;
- restart and report version 2.9.3-beta.4 after installation.

No stable feed is published for this prerelease, so stable-channel users will not receive
beta.4 automatically.

The installer is not Authenticode-signed yet. PulseDeck's internal signed update feed and
SHA-256 verification are separate from Windows SmartScreen.
