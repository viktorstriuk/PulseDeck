# PulseDeck 2.9.3-beta.5

## Clearer setup diagnostics

This beta focuses on setup diagnostics after an installation failure was reported on another Windows machine without enough detail to identify the cause.

- Setup now distinguishes low disk space, write permissions, locked files, interrupted connections, timeouts, DNS/TLS failures, missing sources, HTTP 403/429/5xx responses, proxy authentication and security-software blocks.
- A local diagnostic report is created on failure. It contains technical causes and local paths, but never music, passwords or library contents.
- An “Open report” button now sits beside Retry and reveals the report in Explorer.
- A missing download source offers a direct link to the official PulseDeck repository.
- Compact GitHub, YouTube, Telegram, Twitch and TikTok buttons were added under “Made by MusheP”.

## Verification

The new error states are covered by Go tests and the setup UI is rendered in Chromium in both dark and light system themes, including action-button and social-icon layout checks.
