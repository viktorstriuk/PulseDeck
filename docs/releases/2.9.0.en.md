# PulseDeck 2.9.0 — federated music search

Six toggleable, horizontally reorderable sources: YouTube Music first, YouTube,
SoundCloud, Bandcamp, Newgrounds and Internet Archive. Search metadata no longer
requires provisioning yt-dlp. Debounced typing, cancellation, per-source errors
and retry, native pagination, canonical deduplication and artist/title/album/
duration/version filters share one workspace between an anchored popover and the
expanded dialog, including audio preview.

Availability checks are conservative and limited to visible results: confirmed
DRM/removal may be hidden; network failures, access gates, previews and missing
tools are not misclassified. “Stream found” does not guarantee a completed download.
Chromium networking retains system proxy/PAC support without weakening component
hash/signature verification or TLS. The exact original user-side HTTP failure
cannot be established without that machine's logs.

Optional local recommendations use bounded listening-history JSON, actual elapsed
public-library playback, recency and metadata similarity. Protected music and
previews are excluded. Pause, clear and dismiss controls are provided. Recommendations
are from the existing local library; finding more by an artist is an explicit
online search, not an upload of listening history.

See the detailed research and implementation notes in
[search-2.9.0](../research/search-2.9.0.md). Automated provider tests use fixtures;
live provider downloads and interactive Windows installation were not verified
in the build environment. The installer is unsigned and may need internet access.
