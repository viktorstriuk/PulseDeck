# PulseDeck 2.9.2

## Редактирование трека

ПКМ на треке → **Поменять в треке**. Подменю открывается при наведении;
переименование исполнителя, переименование трека и смена обложки выбираются
нажатием. Два поля редактируются отдельно. Сохранение проверяет ревизию:
изменения, сделанные другим действием во время редактирования, не перезаписываются
молча. Аудиофайл, его имя, идентификатор, избранное и привязка текстов сохраняются.

Правки публичных треков находятся в соседнем `.pulse.json`. Это данные PulseDeck,
**не запись тегов ID3/Vorbis/MP4 внутрь музыки**: другой плеер не обязан их видеть.
Обложки сохраняются отдельно в каталоге данных. При переносе библиотеки на другой
компьютер нужно переносить её данные/обложки, а не только аудиофайлы. У закрытых
треков правятся зашифрованные метаданные; новая обложка также шифруется. Оригинальный
аудиопоток при смене обложки не отзывается.

## Обложки

«Сменить обложку» открывает по клику соседнюю плавающую панель. Наведение на этот
пункт само по себе ничего не ищет. Вверху поле запроса; ниже сетка по четыре
изображения в ряд. Названия/источник находятся в подсказках, не под каждым тайлом.
Сначала выводятся обложки включённых музыкальных источников с текущим приоритетом,
затем обложки релизов MusicBrainz / Cover Art Archive. Отдельная кнопка выбирает
свой PNG, JPEG или WebP. SVG пользователя `select.svg` применяется без изменения
геометрии к отметке выбора в правом верхнем углу; контур использует акцент.

Изображение сохраняется одним кликом, панель остаётся открытой для сравнения.
Запоздавшие ответы старого запроса не заменяют новый; при Escape закрывается
панель, не всё приложение. Существующая выбранная обложка сохраняется в сетке
при новом запросе. Ошибка сети не обозначается как успешный поиск без результатов.

## Одна строка для слов и ссылок

Ссылку на поддерживаемый **одиночный трек** можно вставить в обычную поисковую
строку, включая развёрнутый режим. Отдельная строка «Или вставь ссылку» убрана.
После получения метаданных трек по ссылке закрепляется первым; включённые
источники ищут альтернативы по его исполнителю и названию. В самом поле остаётся
исходная ссылка. Фильтры и переход между окнами её не теряют. Для разрешения ссылки
нужен установленный локальный yt-dlp; отсутствие инструмента и отказ источника
отображаются как ошибки, а не как «найденный» фиктивный результат. Плейлисты по
ссылке здесь не импортируются.

## Плейлисты

ПКМ на плейлисте предлагает только применимые действия: неизвестные исполнители,
обложки и тексты с синхронизацией. Когда действий несколько, они находятся в
«Дополнительно»; когда одно — оно сразу в основном меню; когда нет — пункт отсутствует.
Перед запуском есть подтверждение с числом затрагиваемых треков.

Восстановление исполнителя использует «Исполнитель - Название», а также разделители
«—» и «–» с пробелами. Из названия убирается только найденный префикс. Известный
исполнитель не заменяется. Номер вроде «01 - ...» и неоднозначный «Artist-Track»
не принимаются за надёжное имя. Это локальное преобразование, не онлайн-угадывание.

Автопоиск обложек не меняет существующую картинку. Поиск текстов предпочитает
синхронизированный вариант с совпадающими исполнителем, названием/версией и близкой
длительностью. Уже размеченный текст, явно удалённый текст и отличающийся ручной
текст не затираются. Без достаточного совпадения трек пропускается; при отсутствии
текста появляется сообщение и обрабатывается следующий. Это не распознавание
вокала и не обещание точной синхронизации любой записи.

Очередь показывает прогресс и детали, допускает остановку оставшихся действий.
Законченные правки/копии при остановке не откатываются. Снимок списка библиотеки
используется на весь пакет, но перед записью проверяются текущий файл и его данные.

## Импорт

Перетаскивание аудиофайлов, папок и поддерживаемых архивов в окно сначала запускает
предварительную проверку. Подтверждение показывает число треков и папку назначения,
например «Добавить 3 трека в папку music?». Ни одного аудиофайла не копируется в
библиотеку до подтверждения. Распаковка для проверки происходит во временной
папке импорта, которая очищается при отмене/завершении.

Только нужные улучшения предлагаются компактными переключателями: **Неизвестные
исполнители**, **Обложки**, **Тексты с синхронизацией**. По умолчанию они выключены.
Порядок: копирование → локальное исправление имён → обложки → тексты. Внешним
сервисам передаются запросы с названием/исполнителем, не аудиофайл. Оригиналы не
удаляются; одинаковые имена не перезаписывают существующие файлы.

Поддерживаются **ZIP (stored/deflate), TAR, TAR.GZ, TGZ**. RAR, 7z, ZIP64,
зашифрованные и вложенные архивы не поддерживаются. Защитные лимиты: 2000 треков
за одно подтверждение, 20 000 элементов при обходе/разборе архива, 2 ГиБ на файл,
20 ГиБ суммарного содержимого, 8 ГиБ на входной архив. Недопустимые пути, ссылки,
повреждённый CRC/поток и неподдерживаемый формат отмечаются в деталях. Проверка
не исполняет извлечённые программы и не вызывает внешние архиваторы.

## Установка и проверка

Закрыть PulseDeck и установить в прежнюю папку. Сохранить резервную копию библиотеки
и данных перед обновлением. Независимая установка/проверка компонентов 2.9.1 сохранена.
EXE не подписан Authenticode; Electron/yt-dlp/FFmpeg не включены в этот веб-установщик,
для первой установки нужен интернет.

[Проверки и Windows-чек-лист](../verification-2.9.2.md).
Живые сервисы, Windows drag-and-drop и интерактивная установка в данной среде
не проверены. Иллюстрации используют тестовые треки и иконки вместо реальных обложек.
