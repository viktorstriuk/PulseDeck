# PulseDeck 2.8.0

Раздел автора и лицензий, центр обновлений, проверка подписи и хеша, управляемые
компоненты, собственный графический установщик и безопасные постоянные пути данных.

Официальный источник активен только после задания repo и публичного ключа перед
сборкой. Первый переход со старой или ненастроенной версии — вручную. Закройте
приложение и сохраните резервную копию музыки, data и профиля. Веб-установщику
нужен интернет для закреплённого runtime; FFmpeg/yt-dlp ставятся отдельно.

См. docs/release-checklist.md: публикация не заменяет приёмку на Windows.
