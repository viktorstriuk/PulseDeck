# PulseDeck 2.9.3-beta.3

## Исправление живой сетевой проверки обновлений

Во время настоящей проверки beta.1 → beta.2 приложение на Windows могло открыть
GitHub в браузере, но встроенные проверки PulseDeck и компонентов завершались
сообщением «Не удалось связаться с сервером».

В этой сборке update-транспорт стал устойчивее:

- Chromium `net.fetch` остаётся первым вариантом и сохраняет системный proxy/PAC.
- Если Electron возвращает сырой сетевой сбой до валидного HTTP-ответа (включая
  проблемы manual redirect), запрос повторяется через встроенный Node HTTPS.
- Fallback не применяется к недоверенному URL, HTTP 403/429, таймауту, отмене,
  ошибке размера, хеша или подписи.
- Redirect-цепочка в Node HTTPS по-прежнему проверяется hop-by-hop по allowlist.
- yt-dlp и FFmpeg/FFprobe по-прежнему проверяются независимо у издателей.

Это prerelease. Его нужно установить вручную поверх beta.1/beta.2, а затем выпустить
следующую beta для проверки уже автоматического обновления из исправленной версии.

Установщик пока не подписан Authenticode; подпись внутреннего update-feed и SHA-256
проверяются независимо от Windows SmartScreen.
