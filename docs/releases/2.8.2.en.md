# PulseDeck 2.8.2

Independent surface profiles for windows, menus, context menus, cards, controls,
bars and notifications. Common mode is off by default. Existing styling is
inherited without visual changes; customized profiles survive common-mode
round trips. Restore common style affects only the selected group.

Lyrics reading has no source/export footer. The tools remain in the editor.
After 3.5 seconds of inactivity the text and background fill the window while
chrome and cursor disappear. Mouse movement, scrolling or keyboard input wake
the UI. Editing, dialogs, keyboard-focused controls and active gestures prevent
hiding. Background switches use two bounded layers and a 320 ms opacity fade;
reduced motion disables animation. Protected export preserves the draft and undo
history across password entry, and locking purges both background image layers.

The System swatch follows the OS colour scheme instead of the app palette.
The author artwork is larger and optically raised. New playlist is left-aligned
without a hardcoded grey fill. Pointer focus no longer leaves unwanted outlines;
keyboard focus and selection/drop feedback remain visible.

Sky, Coral and Lime become Rose pearl, Porcelain and Champagne, with pastel
backgrounds and the same dark mark. Legacy preset identifiers remain compatible.

See [verification](../verification-2.8.2.md). Windows x64 installer cross-compiled
in Linux; interactive Windows installation, native appearance and RTSS in a game
were not tested. The installer is unsigned and may need internet to provision
its pinned Electron runtime.
