# Проверки PulseDeck 2.8.2

База: предоставленные исходники 2.8.1. Проверки выполнены 24 сентября 2026 года
в Linux с Node.js 22, Go 1.23.2 и Chromium через Playwright. Версии приложения,
интерфейса установщика и native-помощника согласованы: 2.8.2.

все 15 скриптов завершились кодом 0. Финальный браузерный прогон выполнен
двумя независимыми процессами параллельно; штатный runner воспроизводит те же
наборы последовательно.

## Новая функциональность

Проверены миграция общего стиля, семь независимых групп, переключение
общего режима без потери переопределений, оба варианта сброса, сохранение
между экземплярами renderer, синхронный flush и фильтрация некорректных данных.
Настройки треков, плейлистов, горячих клавиш, языка и иконки сохраняются.
Проверено отсутствие изменения геометрии от декоративной толщины контура.

Системная мини-палитра проверена при противоположной теме приложения,
смене акцента и живом изменении системного светлого/тёмного режима. В VM
проверено, что реальный main.js оставляет Electron `themeSource` в `system`.

Проверены отсутствие панели инструментов в режиме чтения, наличие действий
в редакторе, отсечка до/после 3,5 секунды, полнооконная геометрия, восстановление
мышью/клавиатурой, недоступность скрытых контролов для фокуса, открытые диалоги,
потеря фокуса окна и очистка таймеров при закрытии. Фон имеет ровно два слоя,
opacity-анимацию, ограниченный ожидающий запрос и поддержку reduced motion.
После 24 быстрых переключений отображается последний выбранный вариант.

В наборе с настоящими IPC/хранилищем/шифрованием проверены защищённый экспорт
из редактора, неверный пароль, возврат к несохранённому черновику и истории
отмены, ZIP с исходными байтами аудио и очистка обоих слоёв после блокировки.
Это не только имитация успешного IPC-ответа.

Визуально просмотрены новые градиенты с исходным тёмным знаком, поднятая
аватарка, раздельные настройки и полнооконный текст. Проверены RU/EN и окна
800×600, 1024×768, 1440×1000. Проверено отсутствие контура после клика мышью
и сохранение клавиатурного фокуса на кнопках окна.

## Регрессионные тесты

Старые сценарии общей настройки поверхностей теперь явно включают общий
режим: он больше не является значением по умолчанию. Поиск и экспорт в старых
сценариях открываются из редактора, как в новом интерфейсе. Проверки результата,
геометрии, паролей, сохранения и отмены не отключались. Один первоначальный
packaging-тест ожидал глобальную запись без включения общего режима; он
обновлён под новый сценарий и прошёл полный повторный прогон.

## Сборка и ограничения

Собран Windows x64 PE32+ GUI установщик. Из него извлечены 215 файлов:
208 `app/` и 7 `installer/ui/`. Размеры, SHA-256 и байты сравнивались с манифестом
и рабочими исходниками. Итоговый внешний отчёт выпуска также содержит
результат пересборки очищенного исходного ZIP.

Не выполнялись интерактивная установка/обновление на Windows, работа нативных
системных диалогов на настоящей Windows, RTSS в игре и замеры FPS/энергопотребления
на слабом ПК. Кросс-компиляция и браузерная проверка не заменяют эту приёмку.

Setup не подписан Authenticode. Electron не встроен в EXE: для его получения
может понадобиться интернет. Закреплённая версия среды и механизмы обновлений
унаследованы из переданных исходников и не обновлялись. Официальный репозиторий
и ключ приложения не заданы; источник обновления не угадывается.

## Повторение

```sh
python tools/build-release.py --payload-only
node --test --test-timeout=180000 --test-concurrency=4 tests/*.test.js
node tools/audit-i18n.js
(cd installer/engine && go test -race -count=1 -json ./...)
(cd native && go test -race -count=1 -json ./...)
python tools/run-browser-tests.py
python tools/build-release.py
python tools/extract-embedded.py dist/PulseDeck-Setup-2.8.2.exe /outside/repo/extracted
python tools/package-source.py
```

Машинные результаты и выбранные скриншоты находятся в отдельном архиве
`PulseDeck-2.8.2-test-evidence.zip`, не в исходниках. Архив доказательств содержит
только итоговые результаты, не отладочные неудачные прогоны.
