# Приёмка официального выпуска

## До публикации

- Проверить лицензии/происхождение новых ресурсов и соответствующие исходники
  отдельно распространяемых GPL-инструментов; MIT не распространяется на чужие
  компоненты автоматически.
- Проверить изменения исходников, секреты и историю Git. Repo/public key заданы
  явно, private key хранится вне дерева. Включить protected environment/reviewers.
- Прогнать Node, Go race, i18n, весь Chromium-набор и контроль файлов встроенного
  payload. Создать исходный архив из чистого дерева, не рабочую папку целиком.
- Обновить версию в app, installer/ui, native и заметки ru/en. Подписать финальный
  EXE Authenticode, когда сертификат появится, **до** формирования feed/SHA256.
- Сначала создать draft, загрузить полный комплект, проверить файлы/суммы. Не
  включать prerelease в stable feed. Опубликовать только после ручной приёмки.

## Настоящая Windows x64 (обязательна перед обещанием стабильного автообновления)

Проверить Windows 10/11, DPI 100/125/150/200%, несколько мониторов, собственные
кнопки и прозрачный контур установщика. Логотип не должен обрезаться, область
перетаскивания окна не должна съедать нажатия. Режим reduce-motion без анимаций.

Чистая установка, выбор произвольной разрешённой папки, путь с кириллицей и
пробелами, недостаточные права, закрытие до установки, bootstrap download
cancel/retry, недоступная сеть, нехватка диска, недоверенный/повреждённый runtime,
параллельный Setup, занятый запущенный PulseDeck, ярлык и запись удаления.

Переход со старой 2.7.1 с `music/data/tools` рядом с кодом, сохранение путей,
обложек, приватных плейлистов и несохранённого текста; существующие языковые
overrides, сломанный JSON, дополнительные SVG/языки, повторный запуск миграции.

Две **установленные** предварительные сборки с настоящим GitHub Release:
проверка/уведомление, загрузка/перезапуск, отложенная установка при следующем
старте, смена канала, отмена, 429/503/offline, неверная подпись, подмена файла после
загрузки, отказ закрытия редактора, активный FFmpeg/export, прерывание установки
на каждом этапе, восстановление старого кода и запрет бесконечного retry-loop.

Компоненты: впервые установить pins во время Setup, проверить независимый upstream
без репозитория приложения, отдельно скачать одобренный signed catalog,
обновить пару FFmpeg/FFprobe и отдельный yt-dlp, отказ нового probe, откат,
недопустимые ZIP-пути/symlink, слишком большой архив, занятый компонент. Проверить
изменения upstream на разрешённом для сохранения тестовом контенте.

Удаление: код/ярлыки исчезли, музыка/data/profile/языки не удалены. Повторная
установка видит ту же библиотеку. Старые recovery backups не стираются молча.

В этой подготовленной поставке реальные GitHub Releases, подпись Authenticode,
Windows GUI/перезагрузка и RTSS в игре не были проверены. Их нельзя заменять
скриншотами Chromium или успешной кросс-компиляцией.

## Дополнение 2.9.1

Проверить установку в `D:\Apps\PulseDeck` и папку с кириллицей/пробелами. Удалить
системные инструменты из PATH и убедиться, что Setup подготавливает три локальных
EXE. Затем поставить посторонний yt-dlp в PATH — приложение не должно его запускать.
Удалить только локальный ffprobe.exe: пара должна считаться неполной и восстанавливаться.
Отсутствующая сеть, недоступный Gyan/GitHub и запрет записи должны приводить к
понятной ошибке без переноса компонентов в AppData и без ложного успеха установки.

В UI проверить ввод `The Kid Laroi` посимвольно и пробел после паузы, popup-фильтры,
раскрытие ошибок, wheel/pan и приоритет источников, общую громкость/mute, повторные
переключения общего оформления при прокрученном содержимом. Настройки и поиск
проверить при DPI 125/150/200%, с мышью и с клавиатурой.
