## Что проверяет новый набор

Адаптеры шести источников на контрольных ответах; продолжения страниц, выбор
отдельного оригинала Archive, отсутствие дубликатов и остановка повторной страницы.
Нормализация запросов, операторы, кириллица/транслитерация, нечёткое сходство,
ограниченный приоритет источника и кэш оценки. Неизвестные метаданные не считаются
доказательством несовпадения фильтра.

DRM без ложного срабатывания на 403/429/тайм-аут, приоритет доступного clear-формата,
preview без ложной блокировки. Только два одновременных probe; закрытие очищает
ожидающие проверки. Проверка без загрузчика не устанавливает его автоматически.

Пределы очередей/ответов/кэшей, отмена активных и ожидающих запросов, просроченные
непрозрачные курсоры, HTTPS-allowlist, отсутствие запросов к произвольному хосту,
переадресации, отсутствие бесконечных повторов, доверенный IPC.

Bundled runtime Node 22/23.4/23.5/24, различие permission-флагов, отклонение
неподдерживаемого runtime, реальный запуск текущего Node с выбранным флагом,
передача системного proxy и изолированное окружение дочернего процесса.

Автопоиск и IME, поздние ответы, выключение/возврат источника, pointer/keyboard
перетаскивание, фильтры, подгрузка при скролле, сохранение якоря, общий DOM между
панелью и диалогом, доступность кнопки preview поверх обложки, непрерывность preview
при разворачивании, закрытие Escape/кликом снаружи. Визуальные проверки при
1440×1000, 1024×768 и 800×600, RU/EN и светлой/тёмной теме.

Опциональная история, реальные секунды вместо перемотки, паузы/сон/скорость,
отсутствие protected/preview-записей, очистка ожидающего буфера, ограничение JSON,
локальные рекомендации с объяснением и явный онлайн-поиск по исполнителю.

## Границы доказательства

**Браузерные ответы провайдеров и IPC в новом наборе — контролируемые фикстуры.**
На скриншотах искусственная тестовая библиотека. Эти результаты подтверждают код,
состояния и вёрстку, но не успешный живой запрос к YouTube Music, YouTube,
SoundCloud, Bandcamp, Newgrounds или Archive из пользовательского региона.

Интерактивная установка/запуск на настоящей Windows здесь не проводились.
Сетевые endpoint всех источников и реальные скачивания в этой среде не приняты.
Точная причина исходного `FAILED HTTP REQUEST` на компьютере пользователя без
его журнала не установлена. Исправлены найденные зависимости/сетевой транспорт
и диагностика, а не заявлен универсальный обход сетевых ограничений.

Это Windows x64 web-installer без Authenticode и без встроенного Electron ZIP.
Среда/компоненты при необходимости получаются установщиком/приложением из сети;
SHA-256 и ограничения доверия сохранены. Сама сборка не требует скачивания npm,
Electron или yt-dlp. Поиск по публичным сайтам может ломаться при смене их формата.

## Перед публичным стабильным релизом на Windows

1. Обновить 2.8.2 с существующей библиотекой и отдельно установить в чистый профиль.
   Убедиться, что настройки оформления, защищённые плейлисты и проигрывание сохранены.
2. В свежем профиле без yt-dlp проверить получение списка по каждому источнику,
   включая кириллицу и латиницу, точное название и связку исполнитель/название.
   Проверить подгрузку не меньше трёх страниц и переключение источников во время ввода.
3. Для доступного собственного/разрешённого материала каждого источника проверить
   preview, обычный download, отмену и обрезку. Отдельно проверить трек Archive
   внутри многодорожечного альбома, не загрузку всего альбома вместо одной песни.
4. Повторить с системным proxy/PAC, отключённой сетью, отказом одного источника,
   ограничением 429 и требованием входа. Проверить, что другие результаты остаются,
   сообщения различаются, а unknown не скрывается как DRM.
5. Включить историю, прослушать несколько обычных дорожек, перемотать и поставить
   на паузу. Проверить локальные рекомендации, очистку, отключение и отсутствие
   защищённых дорожек в JSON. «Ещё у исполнителя» должно отправлять только обычный
   запрос после явного нажатия, не выгружать историю.
