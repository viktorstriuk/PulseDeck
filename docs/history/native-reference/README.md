# Исторический справочный исходник

`game-overlay-host-recovered.go` оставлен без изменений из пользовательского архива
восстановленных исходников 2.5.0. Он не является точным исходником ранее поставляемого
EXE (в частности, не содержит его RTSS backend) и сохраняется только для сравнения.

В 2.6.5 он **не компилируется и не встраивается**. Полный текущий модуль, исправления
callback/завершения, тесты и описание восстановления находятся в `../native/`.
Установщик встраивает EXE, собранный из `../native/`, а не прежний бинарник.
