# PulseDeck 2.7.1 — отчёт о выполненных проверках

Дата: 23 сентября 2026 года. База: предоставленные исходники последней сборки
2.7.0. Выпуск содержит Windows x64 Setup и соответствующий архив исходников.
Это отчёт об автоматических и визуальных проверках, а не утверждение о запуске
выпуска на настоящей Windows.

## Результат по замечаниям

**Знак приложения.** В переданных архивах 2.6.8, 2.6.9 и 2.7.0, включая вложенный
архив SVG, оригинального вектора с монитором, пульсом и нотой не найдено.
Знак восстановлен из прежнего `app/assets/app-icons/mono-monitor.png` 512×512.
В `monitor-mark.svg` сохранён полученный вектор; источник и SHA-256 записаны в
`design-source/monitor-mark-provenance.json`. Это восстановленная геометрия,
не найденный авторский SVG и не новая пиктограмма со стрелкой.

Новые «Небо», «Коралл», «Лайм», «Нуар» и конструктор «Своя» используют одну и ту
же геометрию из `app/shared/app-icon.js`. Восемь старых PNG/ICO проверены на
побайтовое совпадение с 2.7.0 — они не изменены. У новых PNG разрешение 512×512,
в ICO включены 16/24/32/48/64/128/256 px. PNG пользовательской иконки и Windows ICO
по-прежнему создаются безопасным ограниченным обработчиком; произвольный SVG
через IPC не принимается.

При наличии сохранённого градиента выбранная старая «Своя» иконка мигрирует один
раз. Цвета и положения точек сохраняются, старый файл не удаляется. Проверены
однократность, повторный запуск, повторное открытие редактора, 1–4 цвета знака,
ограничения числа фоновых точек и безопасность формирования SVG. Повторная
генерация десяти файлов ресурсов в этой среде дала идентичные SHA-256.

**Контуры.** Пользовательская толщина больше не задаёт `border-width`: контур
рисуется внутренней тенью, а размеры компонентов остаются прежними. Для больших
поверхностей используется до 6 px; для обычных кнопок — до 3 px; для компактных
групп и меню — до 2 px. Исправлена исходная высота группы переключателей: её
активный сегмент раньше не помещался целиком даже без пользовательского контура.
В Chromium сравнивались точные координаты и размеры карточки, обложки, текста,
поиска и кнопок до/после 0 → 6 px; изменений геометрии нет. Обложки не пересекаются
с толстым контуром, активные сегменты остаются внутри групп.

**Область применения стиля.** Использованы реальные классы и контейнеры
приложения: карточки, единый контейнер списка, боковая панель, нейтральные кнопки,
поиск, меню и подменю, окна, настройки, импорт, обрезка и нейтральные блоки
редактора. Строки таблицы больше не перекрывают выбранный фон непрозрачной
заливкой. Для стиля «Невидимый» проверено отсутствие заливки, blur и декоративного
контура на основных компонентах. Режим «Только контур» не навязывает минимальную
непрозрачность; сочетание 0% заливки и 0 px контура тоже действительно прозрачно.

Обычные кнопки плейлистов сверху и сбоку исключены из стиля. Оформление получает
только плавающая копия бокового плейлиста во время настоящего перетаскивания.
Линия и свечение плейлиста сохраняются. Обратная связь выделения и цели переноса,
основные/опасные действия, цветовые палитры, обложки и собственное оформление
текстов песен намеренно не превращаются в нейтральные серые поверхности.

**Панель настроек.** Применены карточки, заголовки, типографика и поля из раздела
настроек плеера. Пять вариантов имеют отдельные образцы и состояние выбора.
Ползунки получили видимую дорожку, заливку и область указателя высотой 22 px,
корректную клавиатурную настройку и числовые значения. Выбор цвета использует
существующий HEX/RGB/HSL-диалог, а не случайный системный прямоугольник.
Добавлены сохранение последнего положения, сообщения об ошибке записи,
подсказки и сброс только настроек поверхностей. Неиспользуемые в выбранном режиме
поля отключаются, но их сохранённые значения не теряются.

Дополнительно исправлены потеря первого клика после перемещения плейлистов
из-за перестроения интерфейса на pointerdown и пустая навигация настроек в узком
окне: пиктограммы снова видимы и имеют локализованные доступные подписи.

## Проверка упаковки

Установщик кросс-собран Go для Windows amd64. Игровой помощник пересобран;
повторная сборка помощника совпала по SHA-256. Из окончательного Setup извлечены
и проверены **все 175 файла приложения**: ни одного отсутствующего, лишнего
или несовпадающего файла относительно `app/` в исходниках. Версия встроенного
`package.json` — 2.7.1. Проверка повторяется после формирования ZIP исходников.

Журналы: `node-all.txt`, `browser-*.log`, `browser-*.json`, `native-tests.jsonl`,
`setup-tests.txt`, `i18n-audit.json`, `installer-verification.json`, `summary.json`.

## Границы проверки

Тесты выполнены в Linux. Интерфейс проверялся настоящим Chromium, HTML/CSS/JS,
с тестовым Electron IPC; отдельные наборы используют реальные Node-обработчики,
файлы, шифрование и локальные потоки. **Интерактивная установка и запуск Electron
на Windows, обновление ярлыков/панели задач Windows, регистрация глобальных
горячих клавиш и RTSS непосредственно в игре здесь не выполнялись.** Внешние
YouTube/SoundCloud/LRCLIB-сервисы не использовались как подтверждение готовности.

Установщик и native-помощник не подписаны. Для недостающих компонентов Setup
использует сеть; это не полностью автономный установщик. Изменение версии не
отключает защиту Windows. Перед обновлением следует сохранить `music`, `data`
(включая скрытые файлы) и `%APPDATA%\PulseDeck`, затем выбрать прежнюю папку.

Поздняя обрезка YouTube унаследована из 2.7.0: это повторная загрузка фрагмента
по ссылке, которая может создать дополнительный файл, а не локальное изменение
исходного аудио. Данный выпуск эту функциональность не перерабатывает.
