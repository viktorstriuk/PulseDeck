# PulseDeck 2.7.0 — предварительная сборка установщика

Дата подготовки: 23 сентября 2026 года. База: приложенный архив исходников
2.7.0 из предыдущего сообщения, дополненный исправлениями перед упаковкой.
Это не объявление о завершённом стабильном релизе.

## Файлы

- `PulseDeck-Setup-2.7.0.exe`: Windows x64, Go-установщик с встроенной папкой app.
- `PulseDeck-2.7.0-source.zip`: исходники того же приложения, исходники установщика,
  исходники native-помощника, ресурсы и воспроизводимые проверки.
- `PulseDeck-2.7.0-SHA256SUMS.txt`: контрольные суммы выдаваемых файлов.

Установщик не является автономной поставкой Electron и инструментов импорта.
При отсутствии подходящих компонентов он обращается к адресам загрузки,
заданным в `setup.go`. Он не подписан доверенной цифровой подписью.

## Исправления при подготовке установщика

1. Новые параметры оформления внесены в разрешённые поля `settings:set`.
   Теперь они не теряются из-за фильтрации IPC-патча.
2. Шесть дополнительных действий добавлены в реально отображаемый список
   горячих клавиш. Исходная комбинация сквозных кликов Alt+Shift+P сохранена.
3. Исправлена специфичность CSS переключателя глобальных клавиш и наследование
   цвета подписей кнопок библиотеки.
4. Сохранение своей иконки больше не вызывает отсутствующую `ensureDir`.
   SVG из редактора сначала растеризуется в PNG 256×256 в Chromium.
   Главный процесс проверяет размер/формат PNG и записывает PNG и Windows ICO.
   Произвольный SVG через этот обработчик не записывается.
5. Черновик цветов своей иконки сохраняется в настройках, проходит нормализацию
   и восстанавливается при следующем открытии редактора. Стартовый фон — четыре
   точки, границы количества — 2–7 для фона и 1–4 для символа.
6. Ползунок точки градиента не пересоздаётся при каждом движении. При генерации
   SVG точки упорядочиваются по позиции.
7. Добавлены отсутствовавшие `*-monitor.ico` для новых встроенных вариантов,
   исправлено разрешение пути к пользовательскому ICO для окна/ярлыка.
8. Палитра «Система» использует соответствующие значения фона/поверхности и
   выбранный акцент вместо несвязанных с темой демонстрационных цветов.
9. Исправлены неполные CSS-переменные новых тем и базовые размеры редактора.
   Настройки полного отсутствия фона не оставляют фон/размытие в самой поверхности.

## Известные ограничения и незавершённая проверка

- Полный регрессионный набор всех функций для этой сборки не выполнен.
  Результаты 2.6.9 нельзя считать результатами 2.7.0.
- Интерактивная установка на Windows, запуск Windows Electron, системная
  регистрация клавиш, обновление значка Windows/ярлыка и RTSS в игре здесь
  не проверялись.
- Реальные загрузки YouTube/SoundCloud не выполнялись. Команда обрезки уже
  скачанного YouTube-трека пока повторно использует сетевой сценарий по
  сохранённой ссылке. Она может загрузить и создать ещё один файл, а не
  отредактировать существующий локальный. Это важное отличие от законченного
  локального редактора обрезки.
- Конструктор иконки сейчас использует линейный градиент с позициями точек,
  а не свободное двумерное перемещение цветов по поверхности.
- Визуальные варианты поверхностей не прошли полный аудит всех вложенных меню,
  диалогов и состояний доступности. Тесты упаковки не заменяют этот аудит.
- Доступность сетевых сервисов и всех URL загрузки не гарантируется.

## Установка с сохранением данных

Полностью закрой PulseDeck, включая мини-плеер. Перед обновлением скопируй
папку существующей установки с `music` и `data`, включая скрытые файлы,
и отдельно `%APPDATA%\PulseDeck`. Для обновления выбери в установщике прежнюю
папку приложения. Не удаляй резервную копию до проверки нужных тебе функций.
Предварительную сборку разумно проверять на копии установки/библиотеки;
копия установки сама по себе не изолирует профиль `%APPDATA%\PulseDeck`.

## Повторение сборки

Из корня исходников:

```sh
node tools/audit-i18n.js
node --test tests/packaging-270.test.js tests/i18n-269.test.js
python tests/browser-package-270.py
go test -v setup.go setup_i18n_test.go
# Отдельно из каталога native:
# go test -count=1 ./...
python tools/build-release.py --rebuild-native
python tools/extract-embedded.py dist/PulseDeck-Setup-2.7.0.exe extracted-270
```

Для браузерной проверки нужны Python Playwright и Chromium. Для сборки — Go
1.23 или совместимый более новый компилятор. В среде этой проверки использован
Go 1.23.2. Сам архив исходников не содержит скачанный Electron runtime.
