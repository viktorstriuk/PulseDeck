# PulseDeck 2.6.8

Редактор текста песни, автоматическое сохранение оформления, расширенный поиск и
локальный черновик синхронизации. База — предоставленные исходники 2.6.7.

## Обновление

Полностью закрой приложение, включая трей. Скопируй всю папку установки с `music`
и `data` (включая скрытые файлы/папки), а также `%APPDATA%\PulseDeck` в резервную
копию. Для установленной **2.6.7** предназначен ZIP обновления: скопируй его
`resources` в папку с прежним `PulseDeck.exe`, разреши объединение и замену.
Не удаляй существующую папку и не создавай вложенность `resources/resources`.
Для других версий используй установщик и прежнюю папку приложения.

Установщик использует совместимые компоненты Electron/FFmpeg/yt-dlp повторно,
а недостающие скачивает. Это не автономный пакет. Доверенной подписи нет.
Ручной ZIP не отключает защиту Windows и не снимает блокировку имеющегося EXE.
Игровой помощник EXE и зависимости в этой версии не пересобирались.

Windows, настоящий Electron и игры здесь не запускались. Защищённые плейлисты
остаются экспериментальной функцией без независимого аудита. Новая версия не
раскладывает музыку по папкам артистов и не переписывает теги аудио.

## Что изменилось

Оформление текста применяется немедленно и сохраняется автоматически с коротким
объединением частых изменений. Закрытие окна больше не отменяет настройки.
Статус сообщает об успешной записи или ошибке; при ошибке доступен повтор.
Импорт текста из любого источника, включая JSON, больше не меняет фон.
Автоматическая палитра следует за настоящей обложкой, ручная сохраняется.

Меню «Текст» в редакторе: заменить, найти другую версию, импортировать, удалить.
Удаление затрагивает только текст в PulseDeck, сохраняет аудио и оформление и
предотвращает повторное автоматическое чтение прежнего соседнего файла/тегов.

Поиск очищает служебные приписки, извлекает исполнителя из названия, сравнивает
кириллицу/латиницу, опечатки и порядок слов. Выполняется до восьми разных запросов
после явной команды. Результаты ранжируются, но не применяются автоматически.
Live/remix/acoustic и другие значимые варианты не вычищаются как мусор.
Никаких гарантий полноты внешнего каталога или точного выбора первой версии нет.

Редактор открывается сразу в режиме синхронизации. Вверху — перемотка,
пуск/пауза, ±5 с, скорость прослушивания и повтор выбранной строки/диапазона.
Предпросмотр показывает НЕСОХРАНЁННЫЙ черновик по времени того же аудиоплеера.
Внизу постоянно доступно сохранение. Лишние элементы конца строки скрыты под «…».

Выбирай строки круглыми флажками, слова нажатием. Ctrl добавляет к выбору,
Shift выбирает диапазон. Без выделения сдвиг действует на все строки. Кнопки
±0,1 с сдвигают время, часы открывают ввод произвольного сдвига в секундах.
Групповое действие целиком отменяется Ctrl+Z и повторяется Ctrl+Shift+Z / Ctrl+Y.
Ctrl+A выделяет строки, Ctrl+S сохраняет, T отмечает начало и идёт к следующей.
В полях времени стрелки продолжают редактировать минуты/секунды/миллисекунды.

Стрелки перемещения меняют текст между соседними временными позициями;
внутренние отступы слов перемещаются с фразой. Есть разделение строки перед словом,
очистка меток без удаления текста и явная сортировка строк по времени. Нарушения
хронологии не исправляются скрытно — показываются в предпросмотре. История
ограничена 80 состояниями и приблизительным бюджетом 8 МиБ; после закрытия
редактора не сохраняется. Изменения текста и таймингов требуют «Сохранить».

«По ритму» запускает локальный акустический анализ и предлагает ЧЕРНОВИК начал
строк. Это не распознавание текста, не точное совмещение с вокалом и не надёжное
разделение голоса/инструментов. Алгоритм использует изменения спектра и активность
звука; инструментальный фрагмент может быть принят за вокал. Проверь каждую строку.
Можно задать начало/конец участка и сохранить имеющиеся метки (по умолчанию).
Результат сначала показывается, затем применяется одной отменяемой операцией.
Концы вокальных фраз не выдумываются. Автоматический черновик не записывается
на диск сам. Нет загрузки модели, передачи аудио в сеть или открытого PCM-файла.
Анализ ограничен 30 минутами аудио и 180 секундами работы.

Для закрытой песни анализ идёт через существующий защищённый поток. Оформление
и текст сохраняются зашифрованно; блокировка отменяет анализ и очищает редактор.
Экспорт ZIP всё ещё требует пароль и создаёт внешнюю открытую копию по согласию.

## Проверка и сборка

Подробности и границы: `test-results/TEST-REPORT.md`.
Описание данных: `app/lyrics/FORMAT.md`. Обоснования: `RESEARCH-2.6.8.md`.

Проверенная среда: Node 22.16.0, Go 1.23.2, Python Playwright 1.57.0,
локальный Chromium и FFmpeg под Linux. Тестовые аудио/строки созданы для тестов.

```sh
node --test --test-concurrency=1 tests/*.test.js
(cd native && go test -race -count=1 -v ./...)
python tests/browser-studio-268.py
python tests/browser-lyrics-real-266.py
# Остальные browser-*.py запускаются отдельно. Файлы с номером старой
# версии — регрессионные наборы, которые сейчас проверяют 2.6.8.
python tools/build-release.py
python tools/extract-embedded.py dist/PulseDeck-Setup-2.6.8.exe extracted
```

Сборка по умолчанию сохраняет уже проверенный нативный helper EXE.
`--rebuild-native` нужен только для осознанной пересборки помощника и требует
повторной Windows/RTSS-проверки. Тестовые RPC/VM-мосты находятся только в `tests`;
в установленное приложение они не включаются.
