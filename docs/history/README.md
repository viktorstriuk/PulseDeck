# Исторические материалы

Эти документы, код старого установщика в `.txt` и `native-reference` относятся к
переданным прежним версиям. Действующий код: `installer/engine`, `installer/ui`,
`native`. Исторические отчёты не являются результатами проверок 2.8.0. Скриншоты,
логи и бинарные результаты предыдущих прогонов удалены из публичного дерева.
