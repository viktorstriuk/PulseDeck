# PulseDeck 2.6.9 — отчёт о локализации, проверках и составе выпуска

Дата проверок: **23 сентября 2026 года**. Основа — предоставленные пользователем
исходники PulseDeck 2.6.8. Это отчёт о выполненных проверках, а не утверждение
о проверке всех возможных состояний приложения на Windows.

## Результат

Собраны Windows x64 установщик, ручное обновление **2.6.8 → 2.6.9** и архив
исходников. В `app/languages/ru.json` и `en.json` **по 1 505 ключей**, с одинаковым
набором имён. Встроенная папка `app` содержит **164 файла**. В ручном обновлении
**40 новых/изменённых файлов**, из них 8 новых; удалять старые файлы не требуется.
Игровой помощник пересобран, его бинарный файл включён в оба варианта поставки.

Установщик извлечён обратно: все 164 файла побайтово совпадают с выпускаемым
`app`. Параллельно проверена исходная база: все 156 файлов `app`, извлечённые
из предоставленного установщика 2.6.8, совпадают с предоставленными исходниками.
Применение выпускаемого ZIP к этой базе воспроизводит все 164 файла 2.6.9.
Таким образом, состав обновления проверен не только по списку изменённых путей.

## Что проверялось в новой системе

Единый движок использует только цепочку **выбранный язык → `en.json` → очищенный
ключ**. Он не ищет запасной русский текст в программе или других каталогах.
Пустые, некорректные и отсутствующие значения переходят к следующему шагу.
Для параметров есть безопасная интерполяция; для количественных значений —
множественные формы по локали каталога. В HTML используется экранирование,
в обычных элементах — текст, а не исполняемая разметка из перевода.

Языки обнаруживаются по JSON-файлам. Проверяются имя файла, схема, `meta.name`,
необязательное совпадение `meta.code`, локаль, направление текста и имя SVG.
Некорректный пакет не останавливает загрузку остальных. Проверены ограничения
размера, BOM, неправильные типы сообщений, опасные имена свойств, внешние пути
и символьные ссылки. SVG загружается через `img`, не вставляется как исполняемый
фрагмент DOM. Это ограничение поверхности атаки, не общий аудит SVG-безопасности.

Протестированы добавление и удаление пакета, правка существующего каталога,
наблюдение за файлами без перезапуска, ручное перечитывание, сохранение выбора,
повторная загрузка приложения и отказ записи настроек. При отказе записи
сохраняются предыдущий выбранный язык и значение настройки. Исчезновение
сохранённого пакета не стирает предпочтение: до возвращения JSON действует
запасная английская локализация.

### Область переноса текста

Перенесены основной интерфейс и библиотека, системные категории и сортировка,
контекстные меню и диалоги, загрузки, защищённые плейлисты, уведомления,
все страницы настроек, горячие клавиши, поиск и отображение текста песен,
редактор и его поля тайминга, мини-плеер, помощь и статусы игрового модуля,
собственные подписи файловых диалогов, фоновые ошибки и подписи установщика.
Проверялись также `title`, `aria-label`, `placeholder`, скрытые элементы и
текст CSS-псевдоэлемента, а не только видимые надписи на кнопках.

Идентификаторы протоколов, пути, имена форматов, CSS-селекторы, имена клавиш,
комментарии и документация разработчика не подменялись переводами. Названия
треков, артисты, пользовательские плейлисты, тексты песен и пользовательские
заметки остаются данными. Технический текст внешней ОС, декодера или поставщика
может показываться как подробности локализованной ошибки: он не выдаётся за
собственный перевод приложения. Доступность стороннего сервиса этим выпуском
не меняется.

Ошибки между процессами передают ключ и параметры. Для вызова `lyrics:command`
проверено отображение сообщения HTTP 503 на текущем языке без служебного
префикса `Error invoking remote method`. Смена языка уже показанного сообщения
не требует повторного запроса к сервису. Это проверка сериализации и интерфейса,
а не испытание доступности настоящего сервиса текста.

### Сохранение рабочего состояния

В браузерных сценариях переключение ru/en не меняет аудиоисточник, не ставит
звук на паузу и не сбрасывает позицию. Проверено побайтовое сохранение
несохранённого документа редактора и истории отмены/повтора. Активное поле
тайминга остаётся тем же DOM-элементом; фокус и выделение внутри поля сохраняются.
Подписи единиц, шагов, действий и ошибок обновляются без пересоздания редактора.

Для пустого артиста используется языконезависимая идентичность; переводится
представление, а не метаданные. Системная заметка акустического черновика имеет
ключ, отдельный от пользовательских заметок. Миграция старой стандартной
подписи мини-плеера не должна заменять явно сохранённую пользовательскую подпись
после введения схемы локализации. Эти случаи включены в новые Node.js тесты.

### Статический аудит

`node tools/audit-i18n.js` проверяет 38 JavaScript-файлов, 2 HTML-файла и
CSS-тексты. Он обнаружил 1 289 статических вызовов перевода и 1 486 разных ключей
в статически распознаваемых ссылках; другие ключи включают сообщения Go и
динамически выбираемые значения. Это счётчики формы кода, а не число кнопок.
Проверены равенство ключей ru/en, непустые значения и параметры переводов.

Дополнительно рассмотрены 23 ASCII-кандидата: в них остались технические строки
вроде User-Agent, расположения стороннего RTSS, имени тега `UNSYNCED LYRICS`
и селекторов. Из проверки кириллических литералов исключена таблица декодирования
CP1251 — это данные декодера, не интерфейс. Карта ключей с местами использования
включена в `i18n-key-locations.json`.

Аудит с AST и проверка DOM дополняют друг друга, но не являются математическим
доказательством отсутствия любой надписи во всех недостижимых для теста ветках.
Английский DOM проверялся вместе со скрытыми узлами и доступными названиями;
из поиска русских остатков исключались известные пользовательские значения
фикстур и собственное отображаемое имя языка «Русский».

### Найденные и устранённые недочёты

В ходе повторных проверок исправлены остававшиеся русскими подсказка поиска
и доступные названия редактора, обновление динамических статусов и таймингов,
скрытая подпись запасных цветов визуализатора в CSS. При просмотре скриншотов
исправлены несогласованный стиль кнопок языкового раздела и старая текстовая
привязка, которая заменяла компактный значок исходной разметки текстом.
Для этих последних случаев добавлены отдельные браузерные проверки.

Скриншоты `269-language-en.png`, `269-language-ru.png`, `269-editor-en.png`
и `269-overlay-en.png` приложены к исходникам. Английские настройки и редактор
просмотрены повторно после последней визуальной правки. Основной размер нового
набора — 1440×960; языковые настройки также проверены при 900×660. Прежние наборы
сохраняют свои дополнительные компактные размеры и проверки уменьшенной анимации.

## Сборка и сохранение языков при обновлении

Сборка выполнена Go для Windows amd64 с отключённым CGO. Native helper собран
дважды одинаковой командой: хэши совпали. Установщик содержит окончательные
каталоги ru/en, документацию и тот же native helper, что исходники и ZIP.
Проверены контрольные записи Go embed (NOTSHA256), затем полные хэши и байты
каждого извлечённого файла.

Установщик перед заменой каталога приложения сохраняет пользовательские JSON
и SVG в `data/language-backups/<дата-время>`, переносит дополнительные языки и
иконки, объединяет изменённые переводы с новыми ключами. Повреждённый старый
встроенный пакет остаётся в резервной копии, не вытесняя новый исправный.
Шесть тестов отдельно покрывают этот механизм, некорректные метаданные и
игнорирование символьных ссылок/посторонних файлов. Реальное обновление каталога
Windows с блокировками файлов в этой среде не выполнялось.

Версии, адреса и хэши Electron, yt-dlp и FFmpeg побайтово сверены с константами
исходного `setup.go` 2.6.8 и не изменены. Доступность этих адресов в интернете
здесь не проверялась. Установщик повторно использует подходящие имеющиеся
компоненты и загружает недостающие; это не автономный offline-дистрибутив.
Цифровая подпись отсутствует. Контрольные суммы не заменяют подпись издателя.

## Среда и границы проверки

Среда: Linux x64, Node.js 22.16.0, Python 3.13.5, Chromium 144.0.7559.96,
Go 1.23.2. В тестах загружаются настоящие renderer/overlay-файлы приложения,
но Electron IPC заменён локальными тестовыми мостами. Отдельные интеграционные
сценарии работают с настоящей логикой main, файловой системой, AES/ZIP и
локальными аудиофикстурами. Это не запуск настольного Electron на Windows.

**Не выполнялись:** интерактивная установка и первый запуск на реальной Windows,
проверка системного трея/диалогов/глобальных клавиш в ОС, RTSS в настоящей игре,
онлайн-тестирование всех музыкальных провайдеров, скачивание зависимостей и
независимый аудит безопасности защищённых плейлистов. Подтверждение этих пунктов
не следует выводить из зелёных браузерных тестов или успешной кросс-сборки.

Перед установкой обновления нужно полностью закрыть PulseDeck и сделать
резервную копию папки установки, включая `music`, `data` и скрытые файлы,
а также `%APPDATA%\PulseDeck`. Не удалять её до проверки обновления на своей ОС.

```sh
node tools/audit-i18n.js
node --test tests/*.test.js
(cd native && go test -race -count=1 ./...)
go test -v setup.go setup_i18n_test.go
python tests/browser-i18n-269.py
python tests/browser-regression.py
python tests/browser-features-263.py
python tests/browser-features-264.py

python tests/browser-overlay-265.py

python tests/browser-lyrics-real-266.py
python tools/build-release.py --rebuild-native
python tools/extract-embedded.py dist/PulseDeck-Setup-2.6.9.exe extracted-269
```

Браузерные тесты требуют Python Playwright и Chromium по пути,
указанному в тестах. Интеграционный анализ требует FFmpeg. Внешние зависимости
разработки не устанавливаются сами при распаковке исходников. Формат языкового
пакета, правила параметров и инструкция переводчику — в `app/languages/README.md`.
