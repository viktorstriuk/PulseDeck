## Новые проверки

### Оформление и текст

Немедленное применение размера/цветов, автосохранение до появления текста,
закрытие с завершением отложенной записи, повторное открытие, ошибки записи и
повтор. Запоздавшее сохранение остаётся привязано к исходной песне при её смене.
Управление оформлением не заменяет текстовый документ. Импорт LRCLIB, TXT/LRC
и JSON (включая явный импортированный theme) не сбрасывает текущую палитру.
Автоматическая палитра обновляется при настоящей смене обложки; ручная сохраняется.
Удаление сохраняет музыку/оформление и tombstone вместо самовосстановления слов.

### Поиск

Служебные `(Official Video, 2024)`, `[HD]`, разрешение и кириллические эквиваленты;
сохранение meaningful live/remix/acoustic/remaster; исполнитель в заголовке при
метаданных загрузившего пользователя. Сопоставление Моргенштерн/MORGENSTERN,
опечатки, перестановки букв/слов, несовпадение длительности, дедупликация,
значимые варианты записи. Ограничение числа запросов и размеров, отсутствие
сети без согласия, отмена в том числе во время первоначального чтения файла,
поведение при ошибке сервиса и выдача уже полученной части результатов.

Последняя проверка реального HTTPS-запроса вернула `getaddrinfo EAI_AGAIN
lrclib.net`; журнал `lrclib-live.json`. Нельзя считать успешную работу нового
поиска с живым LRCLIB подтверждённой в этой среде. API-ответы в автоматических
поисковых сценариях контролируемые; никакой «успех» вместо сетевой ошибки не
подставляется в производственный код.

### Редактор

Один реальный аудиоэлемент, пуск/пауза, перемотка, скорость и повтор диапазона.
Подсветка строится по НЕСОХРАНЁННОЙ разметке и текущему времени звука. Сдвиг всех,
выбранных строк и выбранных слов, сохранение остальных эффективных отметок,
диапазон Ctrl/Shift, сохранение выделения при повторном сдвиге. Отмена и повтор
атомарны. Сдвиг за границы не оставляет частичных изменений. Конец необязателен.
Перемещение текста, разделение строки, очистка времён и явная сортировка.
Обработка нарушенной хронологии без скрытого исправления; восстановление
скорости и исходного сохранённого текста после отказа от черновика.

UI снимался и проверялся при 1440×960, 1000×700, 800×600, 600×550. Нет выхода
редактора по ширине, транспорт и нижние действия доступны; строки прокручиваются.
Проверены режим уменьшения анимации и отсутствие непойманных JS-ошибок.

### Реальный акустический тракт и защищённые файлы

Node: реальный дочерний FFmpeg, PCM, Worker, результаты и отсутствие временного
PCM; тишина, повреждённый вход, отсутствующий FFmpeg, отмена/очистка очереди,
отмена во время исходного lookup, неизменность аудио. Границы, сохранённые anchors,
offset и явные инструментальные участки ограничивают черновик. Неизвестные
концы не выдаются за измеренные. Публичный cache ограничен четырьмя записями.

Расширенный браузерный сценарий использовал настоящий main IPC через тестовый
мост: шифрование файлов, защищённый Range-поток, фактическое воспроизведение и
анализ FFmpeg→Worker→редактор. Полная существующая разметка защищена от замены
по умолчанию. После разрешённой замены получен черновик, который отменяется за
один шаг. Оформление автоматически сохраняется зашифрованно и переживает
блокировку/разблокировку. ZIP проверен по CRC и исходным байтам тестового WAV.
В публичной папке текстов закрытой песни нет. Блокировка очищает DOM, выделение,
историю, анализ, виджеты времени и backend-доступ. Тестовый RPC находится только
в `tests`, в приложение/установщик не включается.

Использованы специально созданные фразы и синтетические аудиосигналы, не корпус
размеченных вокальных записей. Поэтому точность определения вокала/слов или
процент правильных таймингов НЕ установлены. Ритмический анализ не является
распознаванием речи, forced alignment или вокальным разделением. На настоящей
песне может потребоваться значительная ручная коррекция, а не «пара мелочей».

## Найденные и исправленные случаи в ходе работы

Импортированная тема нормализовалась к значениям по умолчанию и затем заменяла
оформление. Теперь сохранение текста использует текущую presentation отдельно.
Проверены исходные метки, отмена до запуска ffmpeg/сети, поздний результат после
блокировки, offset акустического черновика и порядок явных проигрышей. Исправлены
потеря выделения при повторном сдвиге и восстановление скорости при закрытии.
Асинхронное событие закрытия старого диалога не очищает повторно открытый редактор.

Старые регрессионные сценарии адаптированы только там, где изменён контракт:
версия 2.6.8, автооткрытие режима времени и сохранение настроек вместо отмены.
Исходный silent WAV не подходит для положительной проверки ритма; для неё
использован новый явно синтетический `studio-audio.wav`, а тишина тестируется
как отказ от выдуманной разметки. Никакие проверки не выдаются за ручной слуховой
аудит песни или запуск оконного EXE.

## Установщик и обновление

Установщик собран Go для Windows x64. Встроенные данные повторно извлечены без
запуска EXE, проверены по встроенным хешам и побайтно сопоставлены с `app`.
Authenticode security directory пуст: доверенной цифровой подписи нет.
Нативный помощник SHA-256 совпадает с предоставленной 2.6.7. ZIP обновления
содержит 16 файлов, не меняет EXE/DLL и точно преобразует app 2.6.7 в app 2.6.8.
Пути, версия и хеши: `installer-verification.json`,
`manual-update-verification.json`, `summary.json`.

Перед установкой нужна резервная копия. Установщик не автономный: недостающие
совместимые компоненты скачиваются. Обновление не обходит Smart App Control.
